    Ejercicios de Funciones y Procedimientos en Java

    Nivel PADAWAN (1 - 10)

    Ejercicios centrados en la sintaxis básica de funciones con uno o dos parámetros y retornos simples.

    Ejercicio 1: Duplicar Valor

    Enunciado: Crea una función que reciba un número entero (N) y devuelva el doble de ese valor.

    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función para que acepte un int y devuelva un int.
      • Comprobación (Trazas): El cuerpo de la función debe ser public static int duplicar(int n).
    2. Cálculo: Dentro de la función, multiplica el parámetro por 2.
      • Comprobación (Trazas): Si se llama con duplicar(7), la operación es 7 * 2 = 14. El retorno debe ser 14.
    3. Llamada y Uso: Desde el método main, llama a la función con un valor y almacena el resultado en una variable para imprimirlo.

    Contexto de Aplicación:

    Cálculo de tarifas o precios que tienen una duplicación por promoción, o el cálculo de memoria requerida para una estructura de datos simple.

    Ejercicio 2: Saludo Personalizado

    Enunciado: Crea un procedimiento que reciba el nombre y la hora actual (enteros) y muestre un saludo formal por consola, adaptando el saludo si la hora es antes o después de las 12 del mediodía.

    Metodología: Divide y Vencerás
    1. Definición de Firma: Define un procedimiento (void) que acepte un String nombre y un int hora.
      • Comprobación (Trazas): La firma debe ser public static void saludar(String nombre, int hora).
    2. Lógica Condicional: Dentro del procedimiento, usa una sentencia if/else para comprobar si hora es menor o igual a 12.
    3. Impresión: Imprime un mensaje diferente ("Buenos días, " vs. "Buenas tardes, ") basado en la condición, concatenando el nombre.
      • Comprobación (Trazas): Si se llama con saludar("Ana", 10), el output debe ser "Buenos días, Ana".

    Contexto de Aplicación:

    Módulos de bienvenida en sistemas de login o dashboards que personalizan la interacción según la hora del día.

    Ejercicio 3: Área de un Rectángulo

    Enunciado: Crea una función que reciba dos números de punto flotante (double) correspondientes a la base y la altura de un rectángulo y devuelva su área.

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función debe recibir dos double y devolver un double.
    2. Cálculo: La lógica de la función es simplemente la multiplicación de los dos parámetros: return base * altura;.
      • Comprobación (Trazas): Si se llama con areaRectangulo(5.0, 3.0), el resultado debe ser 5.0 * 3.0 = 15.0.
    3. Invocación: Llama a la función desde main e imprime el resultado.

    Contexto de Aplicación:

    Módulos de cálculo geométrico en diseño asistido por ordenador (CAD) o videojuegos 2D.

    Ejercicio 4: Verificación de Paridad

    Enunciado: Crea una función que reciba un número entero y devuelva un boolean que indique si el número es par (true) o impar (false).

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función debe recibir un int y devolver un boolean.
    2. Cálculo Módulo: Utiliza el operador módulo (%) para comprobar la paridad. Un número es par si su residuo al dividirlo por 2 es 0.
    3. Retorno: Devuelve el resultado de la expresión lógica: return n % 2 == 0;.
      • Comprobación (Trazas): Si se llama con esPar(4), 4 % 2 = 0, que es true. Si se llama con esPar(5), 5 % 2 = 1, que es false.

    Contexto de Aplicación:

    Filtrado de datos en sistemas de procesamiento por lotes o asignación de tareas a procesadores según su índice de trabajo.

    Ejercicio 5: Mayor de Dos

    Enunciado: Crea una función que reciba dos números enteros y devuelva el valor del número mayor.

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función debe aceptar dos int y devolver un int.
    2. Lógica Condicional: Utiliza una sentencia if/else o el operador ternario para comparar los dos parámetros y retornar el más grande.
      • Comprobación (Trazas): Si se llama con mayor(10, 20), la condición 10 > 20 es false, por lo que debe devolver 20. Si se llama con mayor(50, 50), puede devolver cualquiera de los dos.

    Contexto de Aplicación:

    Algoritmos de ordenamiento simple o la comparación de métricas de rendimiento (ej. CPU vs. RAM) para tomar una decisión.

    Ejercicio 6: Imprimir Secuencia

    Enunciado: Crea un procedimiento que reciba un número entero (N) y muestre todos los números enteros desde 1 hasta N.

    Metodología: Divide y Vencerás
    1. Definición de Firma: Procedimiento (void) que acepta un int n.
    2. Bucle: Dentro del procedimiento, utiliza un bucle for que itere desde i=1 hasta n.
    3. Impresión: En cada iteración, imprime el valor del contador i.
      • Comprobación (Trazas): Si se llama con imprimirSecuencia(5), el bucle debe imprimir 1, 2, 3, 4, 5.

    Contexto de Aplicación:

    Generación de índices o secuencias de identificación en un sistema de impresión de etiquetas o códigos.

    Ejercicio 7: Conversión a Mayúsculas

    Enunciado: Crea una función que reciba una letra (char) minúscula y devuelva su equivalente en mayúscula. No uses funciones de librería (solo aritmética ASCII).

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función debe recibir un char y devolver un char.
    2. Conversión ASCII: El código ASCII de una minúscula es exactamente 32 unidades mayor que el código de su mayúscula correspondiente. La operación es: return (char) (letra - 32);.
      • Comprobación (Trazas): La 'a' es ASCII 97. 97 - 32 = 65, que es 'A'.
    3. Llamada: Prueba la función con un carácter minúscula desde main.

    Contexto de Aplicación:

    Sistemas de validación de entrada de datos donde se requiere estandarizar el texto a un formato específico, como códigos de producto.

    Ejercicio 8: ¿Está en Rango?

    Enunciado: Crea una función que reciba un número entero y dos límites (mínimo y máximo). La función debe devolver true si el número se encuentra dentro del rango (inclusivo) o false en caso contrario.

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función debe aceptar tres int y devolver un boolean.
    2. Lógica Compuesta: La condición es una conjunción de dos cheques: (numero >= min Y numero <= max).
    3. Retorno: Devuelve el resultado de esta expresión lógica compuesta.
      • Comprobación (Trazas): Si se llama con estaEnRango(15, 10, 20), devuelve true. Si se llama con estaEnRango(5, 10, 20), devuelve false.

    Contexto de Aplicación:

    Validación de formularios en el servidor para asegurar que la edad, la cantidad o la puntuación introducida se encuentra dentro de los límites esperados.

    Ejercicio 9: Generar PIN Simple

    Enunciado: Crea una función que no reciba parámetros y devuelva un número entero aleatorio entre 1000 y 9999 (un PIN de 4 dígitos).

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función no acepta parámetros y devuelve un int.
    2. Cálculo Aleatorio: Utiliza la función Math.random(). La fórmula general para un rango [min, max] es (int) (Math.random() * (max - min + 1) + min).
    3. Implementación: El cálculo específico es (int) (Math.random() * 9000 + 1000).
      • Comprobación (Trazas): Llama a la función 3 veces. Verifica que todos los resultados sean números de 4 dígitos (entre 1000 y 9999).

    Contexto de Aplicación:

    Generación de códigos OTP (One-Time Password) o números de referencia temporales para transacciones.

    Ejercicio 10: Sumar Tres

    Enunciado: Crea una función que reciba tres números de punto flotante (double) y devuelva la suma de los tres.

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función debe aceptar tres double y devolver un double.
    2. Cálculo: La función retorna num1 + num2 + num3;.
      • Comprobación (Trazas): Si se llama con sumarTres(1.5, 2.0, 3.5), el resultado debe ser 7.0.
    3. Llamada: Llama a la función en main.

    Contexto de Aplicación:

    Totalización de cuentas de cliente que incluyen un subtotal, impuestos y costes de envío.

    Nivel JEDI (11 - 20)

    Ejercicios que requieren lógica condicional más elaborada, bucles internos o cálculos matemáticos complejos dentro de la función.

    Ejercicio 11: Suma de Rango

    Enunciado: Crea una función que reciba dos enteros A y B y devuelva la suma de todos los números enteros comprendidos entre A y B (ambos inclusive).

    Metodología: Divide y Vencerás
    1. Definición de Firma y Acumulador: La función recibe dos int y devuelve un int. Inicializa suma = 0.
    2. Bucle Interno: Implementa un bucle for que recorra desde el menor de los parámetros hasta el mayor. Asume que A < B por ahora.
    3. Acumulación: Dentro del bucle, suma += i;.
      • Comprobación (Trazas): Si se llama con sumaRango(3, 5), la suma debe ser 3+4+5=12.
    4. Lógica de Orden (Ampliación): Añade una lógica al inicio para asegurar que el bucle siempre vaya del menor al mayor, incluso si el usuario llama con sumaRango(5, 3). (Usa un if para determinar el orden).

    Contexto de Aplicación:

    Cálculo de series matemáticas o la totalización de recursos consumidos durante un período de tiempo definido por un índice inicial y final.

    Ejercicio 12: Clasificación de Nota

    Enunciado: Crea una función que reciba una nota entera (de 0 a 10) y devuelva una cadena de texto (String) con su calificación ("Sobresaliente", "Notable", "Aprobado", "Suspenso").

    Metodología: Divide y Vencerás
    1. Definición de Firma y Casos Base: Recibe un int nota y devuelve un String. Inicializa la cadena de resultado.
    2. Lógica if-else if: Utiliza una estructura condicional anidada para cubrir los rangos:
      • if (nota >= 9): "Sobresaliente".
      • else if (nota >= 7): "Notable".
      • else if (nota >= 5): "Aprobado".
      • else: "Suspenso".
      • Comprobación (Trazas): Prueba calificar(8) debe devolver "Notable". Prueba calificar(4) debe devolver "Suspenso".

    Contexto de Aplicación:

    Sistemas académicos o de evaluación de personal para convertir puntuaciones numéricas en categorías cualitativas.

    Ejercicio 13: Número de Dígitos

    Enunciado: Crea una función que reciba un número entero positivo y devuelva la cantidad de dígitos que contiene.

    Metodología: Divide y Vencerás
    1. Definición de Firma y Contador: Recibe un int n y devuelve un int. Inicializa contador = 0.
    2. Bucle de División: Utiliza un bucle while que se ejecute mientras N sea mayor que 0.
    3. Recorte y Conteo: Dentro del bucle, divide N entre 10 (n = n / 10;) y en el mismo paso incrementa el contador.
      • Comprobación (Trazas): Simula N=543.
        • Iteración 1: n=54, contador=1.
        • Iteración 2: n=5, contador=2.
        • Iteración 3: n=0, contador=3. Fin. El resultado es 3.

    Contexto de Aplicación:

    Validación de longitud de campos numéricos (ej. código postal, DNI) o conversión de números a formato de texto para reportes.

    Ejercicio 14: Potencia (Sin Math.pow)

    Enunciado: Crea una función que reciba una base entera A y un exponente entero positivo B y calcule el valor A elevado a B sin usar el operador de potencia nativo ni Math.pow().

    Metodología: Divide y Vencerás
    1. Definición de Firma y Resultado: Recibe dos int y devuelve un int. Inicializa resultado = 1.
    2. Bucle de Multiplicación: Implementa un bucle for que se ejecute B veces (de i=1 a B).
    3. Multiplicación Acumulativa: Dentro del bucle, multiplica el resultado por la base: resultado *= base;.
      • Comprobación (Trazas): Simula A=3, B=4.
        • Iteración 1: 1 * 3 = 3.
        • Iteración 2: 3 * 3 = 9.
        • Iteración 3: 9 * 3 = 27.
        • Iteración 4: 27 * 3 = 81.

    Contexto de Aplicación:

    Implementación de lógica matemática en entornos de programación de bajo nivel o en la creación de bibliotecas personalizadas.

    Ejercicio 15: Factorial con Condicional

    Enunciado: Crea una función que reciba un número entero N y calcule su factorial N!. La función debe devolver 1 si N es 0, y el factorial si N es positivo. Si N es negativo, debe devolver -1 (como código de error).

    Metodología: Divide y Vencerás
    1. Validación de Error: Usa un if para el caso de error: if (n < 0) devuelve -1.
    2. Caso Base 0!: Usa un else if para el caso N=0, devolviendo 1.
    3. Bucle (Factorial): En el bloque else (para N > 0), implementa el bucle de multiplicación para el cálculo del factorial (ver Ejercicio 11/Padawan para la lógica de bucle).
      • Comprobación (Trazas): Prueba factorial(-5) (devuelve -1). Prueba factorial(3) (devuelve 6).

    Contexto de Aplicación:

    Algoritmos que requieren un resultado matemático complejo y deben incorporar una verificación de parámetros para manejar entradas inválidas.

    Ejercicio 16: Hipotenusa

    Enunciado: Crea una función que reciba las longitudes de los dos catetos de un triángulo rectángulo y devuelva la longitud de la hipotenusa (usando el Teorema de Pitágoras y Math.sqrt()).

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función recibe dos double y devuelve un double.
    2. Cálculo al Cuadrado: Calcula la suma de los catetos al cuadrado: sumaCuadrados = (cateto1 * cateto1) + (cateto2 * cateto2);.
    3. Raíz Cuadrada: Aplica la raíz cuadrada al resultado usando Math.sqrt().
      • Comprobación (Trazas): Si se llama con hipotenusa(3.0, 4.0), la suma de cuadrados es 9.0 + 16.0 = 25.0. La raíz cuadrada es 5.0.

    Contexto de Aplicación:

    Cálculo de distancias euclídeas en sistemas de navegación (GPS) o en gráficos 3D para determinar la longitud de un vector.

    Ejercicio 17: Triángulo Equilátero

    Enunciado: Crea una función que reciba las longitudes de tres lados y devuelva true si pueden formar un triángulo equilátero, o false en caso contrario.

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función acepta tres double y devuelve un boolean.
    2. Lógica de Equilátero: La condición para ser equilátero es que todos los lados sean iguales.
    3. Retorno: Devuelve el resultado de la expresión lógica: return (ladoA == ladoB) && (ladoB == ladoC);.
      • Comprobación (Trazas): Prueba esEquilatero(5.0, 5.0, 5.0) (devuelve true). Prueba esEquilatero(5.0, 5.0, 4.0) (devuelve false).

    Contexto de Aplicación:

    Lógica de motor de geometría en el desarrollo de videojuegos o aplicaciones de realidad aumentada.

    Ejercicio 18: Convertir a Minutos

    Enunciado: Crea una función que reciba dos enteros que representan una cantidad de horas y minutos, y devuelva la cantidad total de minutos que representan.

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función recibe int horas y int minutos y devuelve un int.
    2. Conversión de Horas: Calcula los minutos contenidos en las horas: minutosHoras = horas * 60;.
    3. Suma: Suma este resultado a los minutos originales y retorna el total.
      • Comprobación (Trazas): Si se llama con totalMinutos(2, 30):
        • 2 * 60 = 120.
        • 120 + 30 = 150. El resultado es 150.

    Contexto de Aplicación:

    Sistemas de planificación de tareas (scheduling) o gestión de tiempo que necesitan trabajar con unidades de tiempo atómicas.

    Ejercicio 19: Validar DNI/NIF (Módulo)

    Enunciado: Crea una función que reciba un número entero de 8 dígitos y devuelva el carácter correspondiente de la letra del DNI/NIF. (La letra se obtiene del residuo de dividir el número entre 23, y usar una secuencia fija de 23 letras: TRWAGMYFPDXBNJZSQVHLCKE).

    Metodología: Divide y Vencerás
    1. Cadena Constante: En el main o dentro de la función (como constante), define la cadena LETRAS = "TRWAGMYFPDXBNJZSQVHLCKE".
    2. Cálculo del Módulo: Dentro de la función, calcula el índice: indice = numero % 23.
    3. Extracción de Carácter: El carácter se extrae usando el índice sobre la cadena de letras. Puedes usar LETRAS.charAt(indice).
      • Comprobación (Trazas): Si el número es 12345678, el módulo es 11. El carácter en la posición 11 de la cadena (empezando en 0) es 'D'.
    4. Retorno: La función devuelve el char de la letra.

    Contexto de Aplicación:

    Validación de identidad en sistemas de registro o gestión de bases de datos gubernamentales.

    Ejercicio 20: Conteo de Vocales

    Enunciado: Crea un procedimiento que reciba un carácter y, mediante un switch o if/else if anidados, imprima si es una vocal ('a', 'e', 'i', 'o', 'u') o una consonante. (Asume que solo se ingresan letras minúsculas).

    Metodología: Divide y Vencerás
    1. Definición de Firma: Procedimiento (void) que acepta un char letra.
    2. Lógica switch (Recomendado): Utiliza una sentencia switch que tenga 5 casos (case 'a', case 'e', etc.).
    3. Impresión: Dentro de los case de vocal, imprime "Vocal". Utiliza el default para el caso de "Consonante".
      • Comprobación (Trazas): Prueba clasificarLetra('o') (imprime "Vocal"). Prueba clasificarLetra('b') (imprime "Consonante").

    Contexto de Aplicación:

    Análisis de texto simple o pre-procesamiento de datos lingüísticos en sistemas de inteligencia artificial.

    Nivel MAESTRO JEDI (21 - 30)

    Ejercicios que requieren un diseño de función modular, simulación de recursividad (mediante bucles), o lógica de biblioteca.

    Ejercicio 21: Conversión de Temperatura

    Enunciado: Crea una función que reciba una temperatura en grados Celsius (double) y devuelva su equivalente en grados Fahrenheit. (Fórmula: F = C * (9/5) + 32).

    Metodología: Divide y Vencerás
    1. Definición de Firma: Recibe un double celsius y devuelve un double.
    2. Cálculo de Factor: Asegúrate de que la operación 9/5 se realice usando aritmética de punto flotante (9.0/5.0) para evitar que Java realice una división entera.
    3. Implementación de Fórmula: return celsius * (9.0 / 5.0) + 32.0;.
      • Comprobación (Trazas): La temperatura de congelación es 0°C, que debe dar 32.0°F.

    Contexto de Aplicación:

    Sistemas de monitoreo climático o aplicaciones de utilidad para viajeros que requieren conversión de unidades.

    Ejercicio 22: Encontrar el Mínimo Común Múltiplo (MCM)

    Enunciado: Crea una función que reciba dos enteros A y B y devuelva su Mínimo Común Múltiplo (MCM). (Fórmula: MCM(A, B) = (|A * B|) / MCD(A, B)). Para este ejercicio, debes simular la lógica de buscar el MCD mediante un bucle, si la función no existiera, y luego aplicarlo.

    Metodología: Divide y Vencerás
    1. MCD (Algoritmo de Euclides, Simulado en Bucle): Crea la lógica de una función que encuentre el Máximo Común Divisor (MCD) utilizando el algoritmo de Euclides (simulación de bucle de división y módulo) para obtener el divisor.
    2. Fórmula MCM: Aplica la fórmula principal. Utiliza Math.abs() para obtener el valor absoluto del producto.
    3. Cálculo y Retorno: Devuelve el resultado de la división entre el producto absoluto y el MCD encontrado.
      • Comprobación (Trazas): Si A=4 y B=6. MCD(4, 6)=2. El MCM debe ser (4 * 6) / 2 = 12.

    Contexto de Aplicación:

    Algoritmos de tiempo, como la planificación de eventos recurrentes (ej. dos trenes salen cada 4 y 6 horas, ¿cuándo salen juntos?).

    Ejercicio 23: Invertir Número

    Enunciado: Crea una función que reciba un número entero positivo y devuelva un nuevo entero con los dígitos del número original invertidos (ej. 1234 devuelve 4321).

    Metodología: Divide y Vencerás
    1. Definición de Firma y Acumulador: Recibe un int n y devuelve un int. Inicializa invertido = 0.
    2. Bucle de Descomposición: Utiliza un bucle while mientras N > 0.
    3. Extracción/Recomposición: Dentro del bucle:
      • Obtén el último dígito: digito = n % 10;.
      • Añade el dígito al resultado: invertido = (invertido * 10) + digito;.
      • Recorta el número original: n = n / 10;.
      • Comprobación (Trazas): Simula N=123.
        • Iteración 1: 123 % 10 = 3. invertido=3. 123 / 10 = 12.
        • Iteración 2: 12 % 10 = 2. invertido=32. 12 / 10 = 1.
        • Iteración 3: 1 % 10 = 1. invertido=321. 1 / 10 = 0.

    Contexto de Aplicación:

    Verificación de números palíndromos o procesamiento de secuencias codificadas.

    Ejercicio 24: Es Palíndromo Numérico

    Enunciado: Crea una función que reciba un número entero y devuelva true si es un palíndromo (se lee igual al derecho que al revés), o false en caso contrario. Debe reutilizar la lógica de inversión del número de forma conceptual.

    Metodología: Divide y Vencerás
    1. Lógica Inversora (Delegación Conceptual): Duplica la lógica de inversión del Ejercicio 23 dentro de esta función. Guarda el número original en una variable auxiliar antes de invertirlo.
    2. Comparación: Compara el número original (auxiliar) con el número invertido.
    3. Retorno: Devuelve el resultado de la comparación lógica.
      • Comprobación (Trazas): Si N=121. Invertido es 121. La función debe devolver true. Si N=123. Invertido es 321. La función debe devolver false.

    Contexto de Aplicación:

    Algoritmos de procesamiento de datos para verificar la integridad o el formato de secuencias numéricas.

    Ejercicio 25: Dibujar Línea

    Enunciado: Crea un procedimiento que reciba un carácter y un entero N y muestre N veces ese carácter en la misma línea, seguido de un salto de línea.

    Metodología: Divide y Vencerás
    1. Definición de Firma y Longitud: Procedimiento (void) que acepta un char c y un int n.
    2. Bucle de Impresión: Utiliza un bucle for de 0 a N-1.

    4. Salto de Línea: Después de que el bucle termine, usa System.out.println() (sin parámetros) para avanzar a la siguiente línea.

    Ejercicio 26: Simulación de Dado

    Enunciado: Crea una función que no reciba parámetros y simule el lanzamiento de un dado de 6 caras, devolviendo un entero entre 1 y 6.

    Metodología: Divide y Vencerás
    1. Definición de Firma: Función sin parámetros que devuelve un int.
    2. Generación Aleatoria: Usa Math.random(). La fórmula general para un rango [1, 6] es (int) (Math.random() * 6 + 1).

    Ejercicio 27: Promedio Ponderado

    Enunciado: Crea una función que reciba dos notas y sus respectivos porcentajes de peso (peso1, peso2). Devuelve el promedio ponderado de las dos notas. (Asume que peso1 + peso2 = 100).

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función recibe cuatro double (nota1, peso1, nota2, peso2) y devuelve un double.
    2. Cálculo Ponderado: El cálculo es: ((nota1 * peso1) + (nota2 * peso2)) / 100.0.
      • Comprobación (Trazas): Si Nota A es 10 con 30% y Nota B es 5 con 70%. El cálculo es ((10 * 30) + (5 * 70)) / 100 = (300 + 350) / 100 = 6.5.

    Contexto de Aplicación:

    Sistemas académicos para calcular la nota final de un curso donde diferentes actividades tienen pesos distintos.

    Ejercicio 28: Carácter al Revés

    Enunciado: Crea un procedimiento que reciba una palabra (String) e imprima esa palabra al revés.

    Metodología: Divide y Vencerás
    1. Definición de Firma y Longitud: Procedimiento (void) que acepta un String palabra. Obtén la longitud de la palabra con palabra.length().
    2. Bucle Decremental: Utiliza un bucle for que comience en el índice final de la cadena (length - 1) y vaya hasta 0 (inclusivo).
    3. Impresión de Carácter: Dentro del bucle, imprime el carácter en el índice actual usando palabra.charAt(i). Usa print (sin ln).

    Ejercicio 29: Es Múltiplo

    Enunciado: Crea una función que reciba dos números enteros A y B y devuelva true si A es múltiplo de B, o false en caso contrario.

    Metodología: Divide y Vencerás
    1. Definición de Firma: La función recibe dos int y devuelve un boolean.
    2. Lógica Módulo: Un número A es múltiplo de B si el residuo de la división de A entre B es 0.
    3. Retorno: Devuelve el resultado de la expresión: return a % b == 0;.
      • Comprobación (Trazas): Prueba esMultiplo(10, 5). 10 % 5 = 0, true. Prueba esMultiplo(10, 3). 10 % 3 = 1, false.

    Contexto de Aplicación:

    Filtros de ciclos o periodos en sistemas de calendario y planificación (ej. ¿ocurre un evento cada 3 días?).

    Ejercicio 30: Dibujar Barra de Progreso

    Enunciado: Crea un procedimiento que reciba un entero entre 0 y 100 (porcentaje) y muestre una barra de progreso de 20 caracteres de longitud en la consola, usando el carácter # para el progreso y - para el resto.

    Metodología: Divide y Vencerás
    1. Definición de Firma y Parámetros: Procedimiento (void) que acepta un int porcentaje. Define la LONGITUD_MAXIMA = 20.
    2. Cálculo de Relleno: Calcula cuántos caracteres # se deben imprimir: relleno = (porcentaje * LONGITUD_MAXIMA) / 100.
    3. Bucle de Relleno: Usa un bucle for para imprimir relleno veces el carácter #.
    4. Bucle de Vacío: Usa un segundo bucle for (o continúa el primero) para imprimir los caracteres restantes (-). El conteo debe ir desde relleno hasta LONGITUD_MAXIMA - 1.
    5. Visualización: Imprime el porcentaje al final.
      • Comprobación (Trazas): Si porcentaje=50. relleno es 50 * 20 / 100 = 10. El resultado debe ser ##########---------- 50%.

    Contexto de Aplicación:

    Interfaces de línea de comandos (CLI) o sistemas de gestión de tareas que requieren retroalimentación visual del estado de un proceso.
