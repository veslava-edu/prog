    2 Programacion estructurada ejercicios

    Contexto del Proyecto: Desarrollo del Core para 'Project Chimera'

    ¡Bienvenido al equipo de desarrollo de "Project Chimera"! Nuestro próximo gran lanzamiento es un RPG de texto con una ambientación cyber-noir. Tu primera misión es desarrollar los prototipos de las mecánicas de juego fundamentales. En esta fase, nos centraremos en la lógica pura utilizando exclusivamente las estructuras de control que hemos estudiado: secuencias, condicionales y bucles. Todo el código, por ahora, residirá dentro del método main para concentrarnos en estos pilares. ¡Manos al código!

    Ejercicios de Consolidación

    1) Acceso a la Red Oculta: Sistema de Login | Nivel: Fácil

    Objetivo

    Crear un sistema de autenticación básico para que el jugador acceda al juego, utilizando condicionales simples y operadores lógicos.

    Tarea a realizar

    Escribe un programa que simule una pantalla de login.
    1. Define dos constantes String: USUARIO_REGISTRADO y PASSWORD_REGISTRADA. Asígnales los valores que quieras (ej: "netrunner_01", "cyb3rP@ss!").
    2. Pide al usuario que introduzca su nombre de usuario y su contraseña por consola.
    3. Comprueba si ambos, el usuario y la contraseña introducidos, coinciden con las constantes que definiste. Recuerda usar el método adecuado para comparar String.
    4. Si las credenciales son correctas, muestra un mensaje de bienvenida: "Acceso concedido. Bienvenido a la Red Oculta, [nombre de usuario]".
    5. Si no, muestra un mensaje de error: "Credenciales incorrectas. Intruso detectado".

    Aplicación en el Mundo Real

    Cada aplicación con cuentas de usuario, desde redes sociales hasta sistemas bancarios, utiliza una lógica de autenticación similar a esta como primera barrera de seguridad.

    2) Botín de Dron: Simulador de 'Loot Drop' | Nivel: Fácil

    Objetivo

    Utilizar condicionales anidados (if-else if-else) para simular la obtención de recompensas de diferente rareza al derrotar a un enemigo.

    Tarea a realizar
    1. Crea un programa que simule el botín que suelta un dron de seguridad derrotado.
    2. Genera un número entero aleatorio entre 1 y 100. Este será tu "tiro de suerte".
    3. Implementa la siguiente lógica de recompensas usando una estructura if-else if-else:
      • Si el tiro es mayor a 95, el botín es "Componente Legendario: Matriz de IA corrupta".
      • Si no, si el tiro es mayor a 80, el botín es "Componente Épico: Servomotor mejorado".
      • Si no, si el tiro es mayor a 60, el botín es "Componente Raro: Placa de blindaje de titanio".
      • En cualquier otro caso, el botín es "Componente Común: Chatarra electrónica".
    4. Muestra por pantalla el resultado del tiro de suerte y el botín obtenido.
    Aplicación en el Mundo Real

    Los sistemas de recompensas aleatorias (cajas de botín, 'gachas', 'drops' de enemigos) en los videojuegos se basan enteramente en esta lógica para mantener el interés del jugador.

    3) Hackeando la Terminal: Menú de Opciones | Nivel: Fácil

    Objetivo

    Aplicar la estructura switch para crear un menú interactivo que responda a las elecciones del usuario.

    Tarea a realizar
    1. Diseña un menú de una terminal que el jugador está hackeando. Muestra las siguientes opciones:
      • 1 - Descargar Archivos de Datos
      • 2 - Desactivar Cámaras de Seguridad
      • 3 - Sobrecargar Núcleo de Energía
      • 4 - Salir del Sistema
    2. Pide al usuario que elija una opción (un número del 1 al 4).
    3. Utiliza una estructura switch (la versión tradicional con break) para gestionar la opción elegida.
    4. Para cada case, muestra un mensaje descriptivo de la acción que se está realizando (ej: "Iniciando descarga de 150GB de datos clasificados...").
    5. Incluye un default para manejar el caso en que el usuario introduzca una opción no válida.
    Aplicación en el Mundo Real

    Los menús son omnipresentes en el software, desde los cajeros automáticos y las operadoras telefónicas hasta las interfaces de configuración de cualquier programa. El switch es la herramienta ideal para gestionarlos.

    4) Secuencia de Autodestrucción: La Cuenta Atrás | Nivel: Fácil

    Objetivo

    Implementar un bucle for para ejecutar una acción un número determinado de veces.

    Tarea a realizar
    1. Escribe un programa que simule una cuenta atrás para la autodestrucción de una base enemiga.
    2. Usa un bucle for que cuente hacia atrás desde 10 hasta 1.
    3. En cada iteración, imprime por pantalla "T - [segundo] segundos para la detonación.".
    4. Después de que el bucle termine, imprime "¡BOOM! La base ha sido destruida.".
    Aplicación en el Mundo Real

    Los bucles for se usan constantemente para procesar colecciones de datos de tamaño conocido, como recorrer las filas de una hoja de cálculo, procesar los píxeles de una imagen o, como en este caso, realizar una tarea un número fijo de veces.

    5) Calibración del Ciberdeck: Validación de Entrada | Nivel: Fácil

    Objetivo

    Utilizar un bucle do-while para asegurar que la entrada del usuario cumple con un criterio específico antes de continuar.

    Tarea a realizar
    1. Imagina que el jugador necesita calibrar la potencia de su Ciberdeck, que solo puede operar entre 1 y 100.
    2. Crea un programa que pida al usuario "Introduce el nivel de potencia (1-100):".
    3. Usa un bucle do-while para seguir pidiendo el dato mientras el número introducido sea inválido (menor que 1 o mayor que 100).
    4. Si el usuario introduce un número inválido, muéstrale un mensaje de error como "Error: El nivel de potencia debe estar entre 1 y 100.".
    5. Cuando el usuario finalmente introduzca un valor válido, el bucle terminará y el programa imprimirá "Ciberdeck calibrado a nivel [número] de potencia.".
    Aplicación en el Mundo Real

    La validación de la entrada del usuario es una tarea fundamental en programación para prevenir errores. Se usa en formularios web, configuraciones de software y en cualquier lugar donde un dato incorrecto podría causar un fallo en el sistema.

    6) Depuración: El Bucle Infinito del Droide de Mantenimiento | Nivel: Fácil

    Objetivo

    Analizar un fragmento de código con un error lógico común (un bucle infinito) y corregirlo.

    Setup Inicial

    El siguiente código intenta simular un droide que pule una sección del suelo 10 veces. Sin embargo, el programador junior cometió un error y el droide nunca termina su tarea.

    // --- CÓDIGO CON BUG ---
public class DroideInfinito {
    public static void main(String[] args) {
        int seccionesPulidas = 0;

        System.out.println("Iniciando ciclo de pulido...");

        while (seccionesPulidas < 10) {
            System.out.println("Puliendo sección " + seccionesPulidas + "...");
            // Falta algo aquí...
        }

        System.out.println("Ciclo de pulido completado. El suelo brilla.");
    }
}
    Tarea a realizar
    1. Copia el código anterior en tu editor.
    2. Ejecútalo y observa el comportamiento. ¿Por qué el programa no termina?
    3. Identifica la causa del bucle infinito. La condición seccionesPulidas < 10 nunca se vuelve falsa.
    4. Añade la línea de código que falta dentro del bucle while para que el contador se incremente correctamente y el bucle termine después de 10 iteraciones.
    Aplicación en el Mundo Real

    Los bucles infinitos son uno de los bugs más comunes, especialmente al empezar. Pueden causar que una aplicación se congele o consuma el 100% de la CPU. Saber identificarlos y corregirlos es una habilidad de depuración esencial.

    Ejercicios de Refuerzo

    7) Creación de Personaje: Generador de Atributos | Nivel: Medio

    Objetivo

    Combinar bucles for y condicionales if para crear un sistema más complejo que genere los atributos de un personaje de forma aleatoria.

    Tarea a realizar
    1. Crea un programa para generar los 4 atributos de un personaje: Fuerza, Destreza, Inteligencia y Constitución.
    2. Define un array de String con los nombres de estos atributos.
    3. Usa un bucle for-each para recorrer el array de nombres de atributos.
    4. Dentro del bucle, para cada atributo, simula la tirada de "3 dados de 6 caras" (3d6):
      • Genera tres números aleatorios entre 1 y 6.
      • Suma los tres números para obtener el valor total del atributo.
    5. Añade una regla especial: Si los tres dados sacan el mismo número (ej. tres 5s), es un "éxito crítico". Imprime un mensaje especial junto a la tirada.

    6. Muestra el resultado final de cada atributo, por ejemplo: "Fuerza: 14 (Tirada: 5, 3, 6)".

    7. Pista: Para comprobar el éxito crítico, después de generar los tres números ( dado1, dado2, dado3), una condición simple podría ser: if (dado1 == dado2 && dado2 == dado3).

    Aplicación en el Mundo Real

    La generación procedural de contenido (personajes, mapas, misiones) en videojuegos utiliza combinaciones de bucles y condicionales para crear experiencias únicas en cada partida.

    8) Combate por Turnos: Bucle Principal | Nivel: Medio

    Objetivo

    Estructurar el bucle principal de un sistema de combate, donde la lucha continúa mientras se cumpla una condición.

    Tarea a realizar
    1. Crea un prototipo de combate por turnos entre un "Netrunner" (el jugador) y un "Agente de Seguridad" (el enemigo).
    2. Declara dos variables int: vidaNetrunner (inicializada a 100) y vidaAgente (inicializada a 75).
    3. Crea un bucle while que continúe mientras la vida del Netrunner Y la vida del Agente sean mayores que 0.
    4. Dentro del bucle, simula un turno de combate:
      • Calcula el daño del Netrunner: un número aleatorio entre 5 y 15. Resta este daño a la vidaAgente.
      • Imprime el resultado: "El Netrunner ataca. ¡El Agente pierde [daño] de vida! (Vida restante: [vida])".
      • Importante: Después del ataque del Netrunner, comprueba si la vida del Agente ha caído a 0 o menos. Si es así, usa la instrucción break para salir del bucle inmediatamente.
      • Calcula el daño del Agente: un número aleatorio entre 8 y 12. Resta este daño a la vidaNetrunner.
      • Imprime el resultado: "El Agente contraataca. ¡Pierdes [daño] de vida! (Vida restante: [vida])".

    5. Fuera del bucle, comprueba quién ha ganado (quién tiene vida por encima de 0) e imprime un mensaje de victoria o derrota.

    6. Pista: Para generar un número aleatorio en un rango (ej. entre 5 y 15), puedes usar random.nextInt(MAX - MIN + 1) + MIN. En este caso, random.nextInt(11) + 5.

    Aplicación en el Mundo Real

    El "bucle de juego" (game loop) es el corazón de cualquier videojuego. Es un gran bucle while que se encarga de procesar la entrada, actualizar el estado del juego y renderizar los gráficos, repitiéndose hasta que el juego termina.

    9) Inventario: Búsqueda de Ítem | Nivel: Medio

    Objetivo

    Utilizar un bucle for-each combinado con una variable boolean para buscar un elemento específico dentro de un array.

    Setup Inicial

    El jugador tiene un inventario representado por un array de String: String[] inventario = {"Neuro-Estimulante", "Chip de Datos Encriptado", "Pistola EMP", "Cable de Fibra Óptica"};

    Tarea a realizar
    1. Crea el array inventario del setup inicial.
    2. Pide al usuario el nombre del ítem que desea buscar en su inventario.
    3. Declara una variable boolean llamada encontrado e inicialízala a false.
    4. Usa un bucle for-each para recorrer cada item del inventario.
    5. Dentro del bucle, usa un if para comprobar si el item actual es igual al que busca el usuario (¡recuerda usar .equalsIgnoreCase() para que no importe si lo escribe en mayúsculas o minúsculas!).
    6. Si lo encuentras, cambia la variable encontrado a true y utiliza la instrucción break para detener la búsqueda, ya que no es necesario seguir recorriendo el array.
    7. Después del bucle, usa un if final para comprobar el valor de la variable encontrado. Si es true, imprime "[Ítem Buscado] se encuentra en el inventario.". Si es false, imprime "No tienes ese ítem.".
    Aplicación en el Mundo Real

    La búsqueda de datos en colecciones es una de las operaciones más comunes en programación. Se usa para encontrar un producto en un catálogo, un usuario en una base de datos o un fichero en un directorio.

    Ejercicios de Ampliación

    10) Interfaz de Usuario: Barra de Vida Dinámica | Nivel: Alto

    Objetivo

    Aplicar bucles y lógica condicional para generar una representación visual simple (ASCII art) que cambie en función del valor de una variable.

    Tarea a realizar
    1. Crea un programa que dibuje una barra de vida para un personaje.
    2. Declara dos variables int: vidaActual y vidaMaxima. Dales valores para probar (ej: vidaActual = 7, vidaMaxima = 20).
    3. El programa debe imprimir una barra de vida con el siguiente formato: VIDA: [=======-------------] 7/20
    4. La barra visual dentro de los corchetes [] debe tener una longitud total igual a vidaMaxima.
    5. Usa un único bucle for que itere desde 1 hasta vidaMaxima.
    6. Dentro del bucle, usa un if para decidir qué carácter imprimir en cada paso:
      • Si el contador del bucle es menor o igual a vidaActual, imprime un carácter que represente la vida (ej: =).
      • Si es mayor, imprime un carácter que represente la vida perdida (ej: -).
    7. Asegúrate de construir toda la barra en un String o imprimir los caracteres en la misma línea usando System.out.print() y al final un System.out.println() para el salto de línea.
    Aplicación en el Mundo Real

    La generación dinámica de interfaces de usuario, ya sean gráficas o de texto, se basa en bucles que recorren datos y condicionales que deciden qué elementos visuales mostrar. Este ejercicio es una versión simplificada de cómo se renderizan barras de progreso, medidores de vida o gráficos de barras.

    11) Mini-juego: Desactivando la Bomba | Nivel: Alto

    Objetivo

    Integrar bucles, condicionales y entrada de usuario para crear un mini-juego completo y funcional.

    Tarea a realizar
    1. Crea un juego de "adivina el número" con la temática de desactivar una bomba.
    2. El programa generará un "código de desactivación" secreto (un número aleatorio entre 1 y 100).
    3. El jugador tiene un número limitado de intentos para adivinar el código. Declara una constante INTENTOS_MAXIMOS y dale un valor (ej: 7).
    4. Usa un bucle for que controle el número de intentos. El bucle se ejecutará desde 1 hasta INTENTOS_MAXIMOS.
    5. Dentro del bucle:
      • Informa al jugador de cuántos intentos le quedan.
      • Pide al jugador que introduzca un número.
      • Compara el número del jugador con el código secreto.
        • Si acierta, imprime un mensaje de éxito ("¡Bomba desactivada!") y usa break para salir del bucle.
        • Si falla, dale una pista: "El código es MAYOR" o "El código es MENOR".
    6. Después del bucle, necesitas comprobar si el jugador ha ganado o ha perdido. Una forma de hacerlo es con una variable boolean bombaDesactivada, que se pone a true si acierta. Si al final del juego la variable sigue en false, significa que se han agotado los intentos. Imprime un mensaje de fracaso revelando el código.
    Aplicación en el Mundo Real

    Este tipo de lógica de "ensayo y error" con un número limitado de intentos es la base de sistemas de seguridad (como el PIN del móvil), mecánicas de puzzles en juegos y procesos de calibración en software industrial.

    12) Exploración: Generador de Mapa Procedural | Nivel: Alto

    Objetivo

    Utilizar bucles anidados y números aleatorios para generar una estructura de datos bidimensional, sentando las bases de la generación procedural de contenido.

    Tarea a realizar
    1. Vas a generar un pequeño mapa de 20x10 caracteres. Declara dos constantes int para el ancho y el alto.
    2. Usa un bucle for anidado dentro de otro. El bucle exterior controlará las filas (alto) y el interior las columnas (ancho).
    3. Dentro del bucle interior, en cada "celda" del mapa, decide qué carácter dibujar basándote en una probabilidad aleatoria:
      • Genera un número aleatorio de punto flotante entre 0.0 y 1.0 usando Math.random().
      • Si el número es menor que 0.7 (70% de probabilidad), dibuja un punto . (suelo).
      • Si no, si es menor que 0.9 (20% de probabilidad), dibuja una T (un árbol).
      • Si no (10% de probabilidad restante), dibuja un ~ (agua).
    4. Usa System.out.print() dentro del bucle interno para dibujar los caracteres en la misma línea.
    5. Usa System.out.println() en el bucle externo, justo después de que termine el bucle interno, para crear una nueva línea para la siguiente fila del mapa.
    Revisión por Pares (Peer Review)

    Una vez que tengas tu generador funcionando, intercámbialo con un compañero. * Revisor: Ejecuta el código de tu compañero varias veces. ¿El mapa parece aleatorio? ¿Las proporciones de suelo, árboles y agua parecen correctas según el código? Busca posibles mejoras: ¿se podría añadir un borde al mapa? ¿O un punto de inicio para el jugador ('@')? * Autor: Recibe el feedback y trata de implementar una de las sugerencias de mejora propuestas por tu compañero.

    Aplicación en el Mundo Real

    La generación procedural es una técnica potentísima usada en el desarrollo de juegos para crear mundos masivos (como en No Man's Sky o Minecraft) y en otros campos como la generación de texturas, efectos especiales y simulación de datos.
