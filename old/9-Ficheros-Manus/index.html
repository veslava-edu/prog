    Tema 9: Ficheros en Java - La Guía Definitiva de Persistencia

    Imagina que tu aplicación es un cerebro humano. La memoria RAM es la memoria a corto plazo: rápida, eléctrica, pero volátil; si te das un golpe (o se va la luz), los datos se pierden. Los ficheros, en cambio, son la memoria a largo plazo. Son los libros en la biblioteca, los registros en el archivo y las fotos en el álbum.

    Como desarrolladores de DAW, vuestra misión no es solo procesar datos en el aire (como vimos con los Streams funcionales en el Tema 8), sino garantizar que esos datos sobrevivan al paso del tiempo. En este tema, aprenderemos a dominar desde la humilde lectura de un .txt hasta la gestión de grandes volúmenes de datos binarios y la comunicación entre sistemas mediante formatos universales. ¡Es hora de hacer que tus programas tengan memoria eterna!

    Conceptos Fundamentales

    Para dominar el I/O (Input/Output), primero debemos entender los pilares sobre los que se asienta la arquitectura de Java.

    Definición: Persistencia

    Es la propiedad de los datos de sobrevivir al proceso que los creó. Sin persistencia, cada vez que cerraras Instagram, tendrías que volver a subir todas tus fotos.

    Definición: Encoding (Codificación)

    Es el "traductor" entre los números que entiende el ordenador (bytes) y las letras que entendemos nosotros. UTF-8 es el estándar universal que permite que tu "ñ" no se convierta en un símbolo extraño en el servidor de un cliente en Japón.

    Definición: NIO.2 (New I/O)

    Introducida en Java 7, es la evolución de la entrada/salida. A diferencia de la API antigua, NIO.2 es no bloqueante y está diseñada para trabajar con sistemas de archivos modernos, permitiendo operaciones mucho más rápidas y seguras.

    1. Introducción a los Ficheros

    1.1 ¿Qué es un fichero?

    Un fichero es la forma que tiene el Sistema Operativo de organizar la información en el disco. Para Java, un fichero es simplemente una fuente de la que leer o un destino donde escribir.

    1.2 Tipos de ficheros: texto y binarios

    No todos los ficheros son iguales. Dependiendo de cómo se guarde la información, tenemos dos grandes familias:

    Tipo de Fichero Descripción Ejemplo
    Texto Contienen caracteres legibles por humanos (UTF-8, ASCII). Se organizan en líneas. .txt, .csv, .json, .java
    Binarios Contienen secuencias de bytes que solo una aplicación específica entiende. .jpg, .mp3, .exe, .class

    1.3 Flujos (Streams) de entrada y salida

    En Java, la entrada y salida se basa en el concepto de flujo. Si los datos entran a tu programa, es un InputStream; si salen, es un OutputStream.

    1.4 Entrada/Salida estándar

    Java nos da tres flujos por defecto que ya conoces bien: * System.in: Entrada estándar (normalmente el teclado). * System.out: Salida estándar (la consola). * System.err: Salida de errores (consola, pero para mensajes de pánico).

    1.5 Uso de try-catch con recursos (try-with-resources)

    Antiguamente, cerrar un fichero era un dolor de cabeza. Si te olvidabas, el fichero se quedaba "bloqueado". Desde Java 7, usamos el try-with-resources, que cierra todo automáticamente al terminar.

    Ejemplo 1: Escritura básica segura 

    try (FileWriter writer = new FileWriter("notas.txt")) {
    writer.write("¡Hola DAW! No olvidéis cerrar los flujos.");
} catch (IOException e) {
    System.err.println("Algo salió mal: " + e.getMessage());
}

    Ejemplo 2: Lectura y escritura simultánea 

    try (BufferedReader reader = new BufferedReader(new FileReader("entrada.txt"));
     BufferedWriter writer = new BufferedWriter(new FileWriter("copia.txt"))) {
    String linea;
    while ((linea = reader.readLine()) != null) {
        writer.write(linea);
        writer.newLine();
    }
} catch (IOException e) {
    e.printStackTrace();
}

    Tip

    Usa siempre try-with-resources. Es la diferencia entre un programador junior que deja fugas de memoria y un profesional que mantiene el sistema limpio.

    2. Ficheros y Directorios en Java (NIO.2)

    Java evolucionó de la vieja clase File (del paquete java.io) a la moderna API NIO.2 (java.nio.file). Es como pasar de un coche de los 80 a un Tesla: más rápido, más seguro y con más funciones.

    2.1 Clase File vs Path

    La clase File está obsoleta para muchas cosas. Ahora usamos Path, que es una interfaz que representa una ruta en el sistema.

    Ejemplo 1: Creación de rutas 

    Path p1 = Path.of("C:/datos/config.txt"); // Ruta absoluta
Path p2 = Path.of("config", "app.properties"); // Ruta relativa: config/app.properties

    Ejemplo 2: Conversión entre APIs 

    File viejo = new File("test.txt");
Path nuevo = viejo.toPath(); // De File a Path
File deVuelta = nuevo.toFile(); // De Path a File

    2.2 Operaciones básicas con Files

    La clase Files (en plural) es una navaja suiza con métodos estáticos para hacer de todo.

    Ejemplo 1: Gestión de directorios 

    Path dir = Path.of("logs/2024");
if (Files.notExists(dir)) {
    Files.createDirectories(dir); // Crea toda la jerarquía si no existe
}

    Ejemplo 2: Copia y movimiento atómico 

    Path origen = Path.of("data.txt");
Path destino = Path.of("backup/data_old.txt");
Files.move(origen, destino, StandardCopyOption.REPLACE_EXISTING, StandardCopyOption.ATOMIC_MOVE);

    Ejemplo 3: Lectura rápida de metadatos 

    Path path = Path.of("archivo.zip");
System.out.println("Tamaño: " + Files.size(path) + " bytes");
System.out.println("¿Es ejecutable?: " + Files.isExecutable(path));

    2.3 Directorio resources

    En proyectos profesionales (Maven/Gradle), los ficheros que no cambian (configuraciones, imágenes) van en src/main/resources. Para leerlos, no usamos rutas absolutas, sino el ClassLoader.

    Ejemplo 1: Leer recurso como Stream 

    InputStream is = getClass().getClassLoader().getResourceAsStream("config.properties");

    Ejemplo 2: Obtener URL de un recurso 

    URL resource = getClass().getClassLoader().getResource("logo.png");
Path path = Path.of(resource.toURI());

    Danger

    Nunca uses rutas absolutas como C:\Users\Paco\Desktop\foto.jpg. Si tu programa se ejecuta en el servidor de un cliente o en Linux, fallará estrepitosamente. Usa rutas relativas o recursos.

    3. Flujos de Entrada y Salida (I/O)

    Aquí es donde conectamos las tuberías. Java usa el patrón Decorator, lo que significa que podemos "envolver" un flujo básico con otros que le añaden superpoderes (como el buffering).

    3.1 Streams de bytes (InputStream / OutputStream)

    Se usan para datos binarios (imágenes, audio, etc.).

    Ejemplo 1: Copia de imagen byte a byte (Lento) 

    try (FileInputStream in = new FileInputStream("foto.jpg");
     FileOutputStream out = new FileOutputStream("copia.jpg")) {
    int c;
    while ((c = in.read()) != -1) {
        out.write(c);
    }
}

    Ejemplo 2: Copia con array de bytes (Más rápido) 

    try (FileInputStream in = new FileInputStream("video.mp4");
     FileOutputStream out = new FileOutputStream("copia_video.mp4")) {
    byte[] buffer = new byte[4096];
    int n;
    while ((n = in.read(buffer)) != -1) {
        out.write(buffer, 0, n);
    }
}

    3.2 Streams de caracteres (Reader / Writer)

    Se usan para texto. Manejan automáticamente la codificación (como UTF-8).

    Ejemplo 1: Escribir texto con FileWriter 

    try (FileWriter fw = new FileWriter("mensaje.txt", true)) { // 'true' para append
    fw.write("Añadiendo una línea al final\n");
}

    Ejemplo 2: Leer con FileReader 

    try (FileReader fr = new FileReader("mensaje.txt")) {
    int i;
    while ((i = fr.read()) != -1) System.out.print((char) i);
}

    3.3 Streams con buffer

    Los que debes usar siempre por rendimiento.

    Ejemplo 1: BufferedReader para lectura eficiente 

    try (BufferedReader br = new BufferedReader(new FileReader("grande.txt"))) {
    String linea;
    while ((linea = br.readLine()) != null) {
        System.out.println(linea);
    }
}

    Ejemplo 2: BufferedWriter para escritura masiva 

    try (BufferedWriter bw = new BufferedWriter(new FileWriter("salida.txt"))) {
    for(int i=0; i<1000; i++) {
        bw.write("Línea número " + i);
        bw.newLine();
    }
}

    3.4 PrintWriter y Scanner

    Ejemplo 1: PrintWriter (El más cómodo) 

    try (PrintWriter out = new PrintWriter(new BufferedWriter(new FileWriter("informe.txt")))) {
    out.printf("ID: %d | Nombre: %s | Salario: %.2f\n", 1, "Ana", 2500.50);
}

    Ejemplo 2: Scanner para parsear ficheros 

    try (Scanner sc = new Scanner(new File("datos.csv"))) {
    sc.useDelimiter(",");
    while(sc.hasNext()) {
        System.out.println("Dato: " + sc.next());
    }
}

    Característica Scanner BufferedReader
    Velocidad Lento Muy rápido
    Uso Parsear tokens (números, palabras) Leer líneas completas
    Buffer Pequeño (1KB) Grande (8KB por defecto)

    4. Ficheros de Texto y Binarios

    4.1 Lectura y Escritura de Texto (La forma moderna)

    Con Java 8+, leer un fichero de texto completo es ridículamente fácil gracias a los Streams funcionales.

    Ejemplo 1: Leer todas las líneas y filtrarlas 

    Path path = Path.of("logs.txt");
Files.lines(path)
     .filter(line -> line.contains("ERROR"))
     .forEach(System.out::println);

    Ejemplo 2: Escribir una lista de Strings de golpe 

    List<String> lineas = List.of("Línea 1", "Línea 2", "Línea 3");
Files.write(path, lineas, StandardCharsets.UTF_8);

    Ejemplo 3: Leer todo el contenido a un String 

    String contenido = Files.readString(path);

    4.2 Ficheros de Acceso Aleatorio (RandomAccessFile)

    Imagina un libro. Normalmente lo lees de la página 1 a la 100. Pero si quieres ir directo a la página 42, necesitas Acceso Aleatorio.

    Ejemplo 1: Leer en una posición específica 

    try (RandomAccessFile raf = new RandomAccessFile("datos.dat", "r")) {
    raf.seek(100); // Saltamos al byte 100
    int valor = raf.readInt();
}

    Ejemplo 2: Sobrescribir datos en medio del fichero 

    try (RandomAccessFile raf = new RandomAccessFile("config.bin", "rw")) {
    raf.seek(10);
    raf.writeBoolean(true);
}

    4.3 Serialización de Objetos

    La serialización es el proceso de convertir un objeto Java en una secuencia de bytes.

    Ejemplo 1: Clase Serializable 

    public class Jugador implements Serializable {
    private static final long serialVersionUID = 1L;
    private String nombre;
    private transient String password; // No se serializa
}

    Ejemplo 2: Guardar y cargar objeto 

    // Guardar
try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("save.dat"))) {
    oos.writeObject(new Jugador("Paco"));
}
// Cargar
try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("save.dat"))) {
    Jugador j = (Jugador) ois.readObject();
}

    5. Formatos de Intercambio: JSON y XML

    5.1 JSON (Jackson)

    Ejemplo 1: Objeto a JSON 

    ObjectMapper mapper = new ObjectMapper();
String json = mapper.writeValueAsString(new User("Ana", 20));

    Ejemplo 2: JSON a Objeto 

    User user = mapper.readValue(new File("user.json"), User.class);

    Ejemplo 3: Pretty Print 

    mapper.enable(SerializationFeature.INDENT_OUTPUT);
mapper.writeValue(System.out, miObjeto);

    5.2 XML

    Ejemplo 1: Marshalling (Objeto a XML) 

    JAXBContext context = JAXBContext.newInstance(Persona.class);
Marshaller m = context.createMarshaller();
m.marshal(persona, new File("persona.xml"));

    Ejemplo 2: Unmarshalling (XML a Objeto) 

    Unmarshaller um = context.createUnmarshaller();
Persona p = (Persona) um.unmarshal(new File("persona.xml"));


    Laboratorio Práctico: Programas por Formato

    A continuación, se presentan programas completos para operar con cada formato.

    1. Programa: Gestor de Texto Plano (.txt)

    import java.nio.file.*;
import java.io.*;
import java.util.*;

public class TextManager {
    public static void main(String[] args) throws IOException {
        Path path = Path.of("diario.txt");
        // Escribir
        Files.writeString(path, "Querido diario: Hoy aprendí I/O en Java.\n", StandardOpenOption.CREATE, StandardOpenOption.APPEND);
        // Leer
        System.out.println("Contenido: " + Files.readString(path));
    }
}

    2. Programa: Procesador de CSV (.csv)

    import java.io.*;

public class CSVProcessor {
    public static void main(String[] args) {
        String line;
        try (BufferedReader br = new BufferedReader(new FileReader("productos.csv"))) {
            while ((line = br.readLine()) != null) {
                String[] campos = line.split(",");
                System.out.println("Producto: " + campos[0] + " | Precio: " + campos[1]);
            }
        } catch (IOException e) { e.printStackTrace(); }
    }
}

    3. Programa: Persistencia Binaria (.dat)

    import java.io.*;

public class BinarySave {
    public static void main(String[] args) throws Exception {
        // Guardar
        try (DataOutputStream dos = new DataOutputStream(new FileOutputStream("game.bin"))) {
            dos.writeInt(100); // Vida
            dos.writeUTF("Nivel 1"); // Nombre nivel
        }
        // Leer
        try (DataInputStream dis = new DataInputStream(new FileInputStream("game.bin"))) {
            System.out.println("Vida: " + dis.readInt());
            System.out.println("Nivel: " + dis.readUTF());
        }
    }
}

    4. Programa: Configuración JSON (Jackson)

    import com.fasterxml.jackson.databind.ObjectMapper;
import java.io.File;

class Config { public String db; public int port; }

public class JSONConfig {
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();
        Config cfg = new Config(); cfg.db = "localhost"; cfg.port = 3306;
        // Guardar
        mapper.writeValue(new File("config.json"), cfg);
        // Cargar
        Config loaded = mapper.readValue(new File("config.json"), Config.class);
        System.out.println("DB: " + loaded.db);
    }
}

    5. Programa: Acceso Aleatorio (Mini-DB)

    import java.io.RandomAccessFile;

public class RandomDB {
    public static void main(String[] args) throws Exception {
        try (RandomAccessFile raf = new RandomAccessFile("db.bin", "rw")) {
            raf.writeInt(101); // Registro 1
            raf.writeInt(202); // Registro 2
            raf.seek(0); // Volver al inicio
            System.out.println("Primer registro: " + raf.readInt());
        }
    }
}

    10. Resumen y Buenas Prácticas

    1. Cierra siempre los recursos: Usa try-with-resources.
    2. Usa Buffers: No leas byte a byte.
    3. Prefiere NIO.2: Usa Path y Files.
    4. Codificación: Usa siempre UTF-8.
