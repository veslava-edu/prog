    Módulo de Prácticas: Estructuras Estáticas de Datos (Arrays 1D) en JAVA

    ¡Saludos! Hoy nos sumergiremos en la base de la gestión de datos: los arrays unidimensionales.

    Introducción Rápida a Arrays en JAVA

    Un array (o arreglo) en Java es una colección estática de elementos del mismo tipo. "Estático" significa que su tamaño se define al crearse y no puede cambiar.

    Concepto Sintaxis en JAVA Descripción
    Declaración int[] miArray; Indica que miArray será un array de enteros.
    Inicialización miArray = new int[5]; Crea el array y le asigna un tamaño fijo de 5 elementos.
    Inicialización Literal int[] miArray = {10, 20, 30}; Crea e inicializa con valores concretos. El tamaño es 3.
    Asignar/Leer Valor miArray[0] = 5; int x = miArray[0]; La indexación comienza siempre en 0 (cero).
    Longitud miArray.length Devuelve el tamaño (cantidad de elementos).
    Recorrido Básico for (int i = 0; i < miArray.length; i++) { ... } Se usa un bucle para acceder a cada elemento por su índice.

    Nivel PADAWAN (1 - 7)

    Ejercicios centrados en la inicialización, el recorrido y las operaciones básicas de lectura.

    1) Mostrar Valores de un Array

    Objetivo:

    Declarar, inicializar y recorrer un array para mostrar sus valores.

    Tarea a realizar:
    1. Crea un método mostrarValores(int[] lista).
    2. En el main, declara e inicializa un array int[] con 7 valores.
    3. Llama al método para imprimir cada valor, indicando su posición (índice).
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define el procedimiento (void) que acepta un array de enteros.
    2. Bucle Indexado: Usa un bucle for inicializado en 0 y que se ejecute mientras el índice sea menor que la longitud del array (lista.length).
    3. Visualización: Dentro del bucle, imprime el índice (i) y el valor del elemento (lista[i]).
    4. Comprobación (Trazas): Verifica que el primer valor impreso corresponda al índice 0 y el último al índice length - 1.

    Concepto Clave:

    Uso correcto de for (int i = 0; i < lecturas.length; i++) para garantizar el acceso a todos los índices.

    2) Sumar Elementos

    Objetivo:

    Recorrer un array para calcular la suma total de sus elementos.

    Tarea a realizar:
    1. Implementa una función calcularSuma(int[] valores) que reciba un array de enteros y devuelva la suma total de todos sus elementos.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Acumulador: Define la función (retorna int) e inicializa una variable suma = 0 fuera del bucle.
    2. Iteración: Crea un bucle que recorra todos los elementos del array (de 0 a length - 1).
    3. Acumulación: Dentro del bucle, suma el valor del elemento actual al acumulador: suma = suma + valores[i].
    4. Retorno: Devuelve el valor final de suma.
    5. Comprobación (Trazas): Si el array es {1, 2, 3}, verifica que la suma sea 3 después de la iteración 2 y 6 al finalizar.

    Concepto Clave:

    Inicializar una variable acumuladora (suma = 0) fuera del bucle y actualizarla dentro del bucle.

    3) Encontrar el Máximo

    Objetivo:

    Encontrar el valor máximo dentro de un array.

    Tarea a realizar:
    1. Implementa una función encontrarMaximo(int[] datos) que devuelva el valor más alto del array.
    2. Asume que el array nunca estará vacío.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función que retorna int.
    2. Inicialización del Máximo: Inicializa la variable maximo con el primer elemento del array: maximo = datos[0].
    3. Iteración y Comparación: Crea un bucle que comience desde el segundo elemento (índice 1).
    4. Condicional: Dentro del bucle, usa un if para comparar: si datos[i] > maximo, actualiza maximo = datos[i].
    5. Retorno: Devuelve el valor final de maximo.
    6. Comprobación (Trazas): Usa el array {10, 5, 20}. Verifica que maximo se inicialice en 10, y que se actualice correctamente a 20.

    Concepto Clave:

    Inicializa la variable maximo con el valor del primer elemento (datos[0]) para asegurar que la comparación inicial funcione correctamente con cualquier conjunto de números.

    4) Encontrar el Mínimo

    Objetivo:

    Encontrar el valor mínimo dentro de un array.

    Tarea a realizar:
    1. Implementa una función encontrarMinimo(int[] datos) que devuelva el valor más bajo del array (asumiendo todos los valores son positivos).
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función que retorna int.
    2. Inicialización del Mínimo: Inicializa minimo = datos[0].
    3. Iteración y Comparación: Recorre el array desde el índice 1.
    4. Condicional: Dentro del bucle, usa un if para comparar: si datos[i] < minimo, actualiza minimo = datos[i].
    5. Comprobación (Trazas): Usa el array {10, 5, 20}. Verifica que minimo se actualice de 10 a 5.

    Concepto Clave:

    La lógica es inversa a la de buscar el máximo: dentro del bucle, usa if (datos[i] < minimo).

    5) Calcular el Promedio

    Objetivo:

    Combinar la suma y la longitud del array para calcular el promedio.

    Tarea a realizar:
    1. Implementa una función calcularPromedio(int[] valores) que devuelva el promedio como un valor double.
    2. Asegúrate de manejar el casting de tipos para que la división sea flotante. Si el array está vacío, devuelve 0.0.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función que retorna double.
    2. Validación de Longitud: Usa un if para verificar si valores.length == 0. Si es así, retorna 0.0.
    3. Cálculo de Suma: Implementa un bucle para calcular la suma de todos los elementos (ver Ejercicio 2).
    4. División y Casting: Retorna la división de la suma por la longitud, asegurando que la suma sea tratada como double: return (double) suma / valores.length;.
    5. Comprobación (Trazas): Usa el array {10, 20}. Verifica que la suma sea 30 y que el resultado sea 15.0.

    Concepto Clave:

    Antes de la división, convierte la suma a double para evitar que Java realice una división entera que truncaría el resultado.

    6) Contar Elementos Mayores que un Umbral

    Objetivo:

    Contar cuántos elementos en un array cumplen una condición de umbral.

    Tarea a realizar:
    1. Implementa una función contarSuperiores(int[] lista, int umbral) que devuelva la cantidad de elementos en el array que son estrictamente mayores que el umbral.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Contador: Define la función (retorna int) e inicializa un contador a cero: int contador = 0;.
    2. Iteración: Recorre el array con un bucle for.
    3. Condicional: Dentro del bucle, usa un if: si lista[i] > umbral, incrementa contador.
    4. Retorno: Devuelve el valor final de contador.
    5. Comprobación (Trazas): Usa {95, 80, 100} y umbral=90. Verifica que solo se incremente el contador para 95 y 100, retornando 2.

    Concepto Clave:

    Usa un contador (int contador = 0;) y un if dentro del bucle: if (niveles[i] > umbral).

    7) Encontrar la Posición de un Valor

    Objetivo:

    Buscar la posición (índice) del primer elemento que cumple una condición.

    Tarea a realizar:
    1. Implementa una función encontrarIndice(long[] datos, long valorBusqueda) que devuelva el índice de la primera vez que se encuentra el valorBusqueda.
    2. Si el valor no se encuentra en el array, el método debe devolver el valor especial -1.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función que retorna int.
    2. Iteración: Recorre el array con un bucle for utilizando el índice i.
    3. Condicional y Retorno Temprano: Dentro del bucle, usa un if para comparar datos[i] == valorBusqueda. Si son iguales, retorna i inmediatamente.
    4. Retorno por Defecto: Si el bucle termina sin encontrar el valor (es decir, el return i nunca se ejecutó), retorna -1.
    5. Comprobación (Trazas): Usa {10, 20, 30} y busca 20. Verifica que retorne 1. Busca 50, verifica que retorne -1.

    Concepto Clave:

    Si se encuentra la coincidencia, usa return i dentro del bucle para terminar la función inmediatamente. Si el bucle termina, usa return -1.

    Nivel JEDI (8 - 14)

    Ejercicios que requieren un manejo más complejo del recorrido, la creación de nuevos arrays o la modificación de datos in-place.

    8) Imprimir al Revés

    Objetivo:

    Recorrer un array de manera inversa.

    Tarea a realizar:
    1. Implementa un procedimiento imprimirInverso(int[] datos) que imprima todos los elementos del array en orden inverso, sin modificar el array original.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define el procedimiento (void).
    2. Bucle Decremental: Usa un bucle for con la inicialización i = datos.length - 1, la condición i >= 0 y el operador de decremento i--.
    3. Visualización: Dentro del bucle, imprime el elemento datos[i].
    4. Comprobación (Trazas): Usa {1, 2, 3}. Verifica que la secuencia de impresión sea 3, 2, 1.

    Concepto Clave:

    El bucle debe iniciar en datos.length - 1, tener la condición i >= 0 y usar el decremento i--.

    9) Filtrar Valores Positivos

    Objetivo:

    Crear un nuevo array a partir de un filtro.

    Tarea a realizar:
    1. Implementa una función filtrarPositivos(double[] datos) que devuelva un nuevo array de double conteniendo solo los valores del array original que sean mayores o iguales a 0.0.
    2. Pista: Esto requiere dos bucles: uno para contar los elementos válidos (para determinar el tamaño del nuevo array) y otro para rellenarlo.
    Metodología: Divide y Vencerás
    1. Conteo de Válidos: Usa un primer bucle para recorrer datos y contar cuántos elementos son $>= 0.0$ (almacena el resultado en contador).
    2. Creación de Array Resultante: Crea el nuevo array con el tamaño exacto: double[] resultado = new double[contador];.
    3. Relleno: Usa un segundo bucle para recorrer datos de nuevo.
    4. Copia Condicional: Dentro del segundo bucle, si un elemento es válido, cópialo a resultado[j] y luego incrementa el índice del resultado (j).
    5. Comprobación (Trazas): Usa {-5, 10, -1, 5}. Verifica que contador=2. El array resultante debe ser {10.0, 5.0}.

    Concepto Clave:

    Manejar dos índices: i para el array original y un índice separado (j o indiceNuevo) para el nuevo array.

    10) Reemplazar Valores Negativos por Cero

    Objetivo:

    Modificar un array in-place (sin crear uno nuevo) basándose en una condición.

    Tarea a realizar:
    1. Implementa una función reemplazarNegativos(int[] datos) que modifique el array datos de forma que cualquier valor negativo sea reemplazado por 0.
    2. La función debe devolver la cantidad de valores que fueron reemplazados.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Contador: Define la función (retorna int) e inicializa reemplazados = 0.
    2. Bucle Indexado: Usa un bucle for con el índice i para poder modificar el array.
    3. Modificación Condicional: Dentro del bucle, si datos[i] < 0:
      • Establece datos[i] = 0.
      • Incrementa reemplazados.
    4. Comprobación (Trazas): Usa {10, -5, 2}. Verifica que el array se modifique a {10, 0, 2} y que la función retorne 1.

    Concepto Clave:

    El bucle debe acceder a los elementos por índice (datos[i]) para poder modificar su valor directamente.

    11) Comparar si Dos Arrays Son Idénticos

    Objetivo:

    Comparar si dos arrays del mismo tipo son exactamente iguales.

    Tarea a realizar:
    1. Implementa una función sonIguales(int[] listaA, int[] listaB) que devuelva true si ambos arrays tienen la misma longitud y sus elementos coinciden en el mismo orden, y false en caso contrario.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función que retorna boolean.
    2. Chequeo de Longitud: Comprueba si listaA.length != listaB.length. Si son diferentes, retorna false inmediatamente.
    3. Iteración y Comparación: Usa un bucle for para recorrer los arrays desde 0 hasta length - 1.
    4. Retorno Temprano: Dentro del bucle, si listaA[i] != listaB[i], retorna false inmediatamente.
    5. Retorno de Éxito: Si el bucle finaliza sin retornar false, significa que son iguales, así que retorna true.
    6. Comprobación (Trazas): Compara {1, 2} con {1, 3}. Verifica que retorne false en el índice 1.

    Concepto Clave:

    El primer paso debe ser un if para comparar listaA.length != listaB.length. Si difieren, puedes retornar false inmediatamente.

    12) Comprobar Elementos Comunes

    Objetivo:

    Implementar una búsqueda dentro de una búsqueda (bucle anidado) para verificar si un valor de un array existe en otro.

    Tarea a realizar:
    1. Implementa una función hayCoincidencia(int[] listaA, int[] listaB) que devuelva true si cualquier valor del array listaA se encuentra en el array listaB.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función que retorna boolean.
    2. Bucle Externo: Recorre el primer array (listaA) con un índice i.
    3. Bucle Interno: Dentro, usa un bucle anidado que recorra el segundo array (listaB) con un índice j.
    4. Condicional y Retorno Temprano: Dentro del bucle interno, si listaA[i] == listaB[j], retorna true (coincidencia encontrada).
    5. Retorno de Fracaso: Si el bucle externo finaliza (es decir, se revisó cada elemento de A contra todo B), retorna false.
    6. Comprobación (Trazas): Usa A={1, 5}, B={3, 5}. Verifica que retorne true cuando i=1 y j=1.

    Concepto Clave:

    Utiliza un bucle externo que recorra listaA y un bucle interno que, para cada elemento, recorra listaB en busca de una coincidencia.

    13) Rotar a la Derecha

    Objetivo:

    Modificar un array in-place rotando sus elementos una posición a la derecha.

    Tarea a realizar:
    1. Implementa un procedimiento rotarDerecha(long[] datos) que mueva los elementos una posición a la derecha. El último elemento debe pasar a ser el primero.
    2. Pista: Guarda el último elemento en una variable temporal antes de empezar el bucle.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Almacenamiento: Define el procedimiento (void). Almacena el último valor: long temp = datos[datos.length - 1];.
    2. Bucle de Desplazamiento: Usa un bucle for que recorra el array de derecha a izquierda (desde i = datos.length - 1 hasta i > 0).
    3. Asignación de Desplazamiento: Dentro del bucle, cada elemento toma el valor del que tiene a su izquierda: datos[i] = datos[i - 1];.
    4. Restauración del Primero: Fuera del bucle, asigna el valor guardado al primer elemento: datos[0] = temp;.
    5. Comprobación (Trazas): Usa {10, 20, 30}. temp=30. Verifica que el array final sea {30, 10, 20}.

    Concepto Clave:

    El bucle debe recorrer el array de derecha a izquierda (i = length - 1; i > 0; i--) para que cada elemento sobrescriba al anterior antes de que su valor se pierda.

    14) Sumar Dos Arrays Elemento a Elemento

    Objetivo:

    Crear un nuevo array a partir de la suma de los elementos de dos arrays.

    Tarea a realizar:
    1. Implementa una función sumarArrays(double[] listaA, double[] listaB) que devuelva un nuevo array de double donde cada elemento es la suma de los elementos correspondientes en listaA y listaB.
    2. Asume que los arrays de entrada tienen la misma longitud.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Creación de Array: Define la función (retorna double[]). Crea el array resultado con la misma longitud: double[] resultado = new double[listaA.length];.
    2. Iteración: Usa un bucle for desde 0 hasta length - 1.
    3. Suma y Asignación: Dentro del bucle, calcula la suma de los elementos correspondientes y asigna al array resultado: resultado[i] = listaA[i] + listaB[i];.
    4. Retorno: Devuelve el array resultado.
    5. Comprobación (Trazas): Usa A={1.0, 2.0}, B={0.5, 1.5}. Verifica que resultado[0] sea 1.5 y resultado[1] sea 3.5.

    Concepto Clave:

    Declara el nuevo array con la longitud común: double[] resultado = new double[listaA.length];.

    Nivel MAESTRO JEDI (15 - 20)

    Ejercicios que requieren la implementación de algoritmos más complejos, a menudo utilizando la técnica de dos punteros o bucles anidados sofisticados.

    15) Ordenar el Array (Ascendente)

    Objetivo:

    Implementar un algoritmo de ordenación simple (in-place).

    Tarea a realizar:
    1. Implementa un procedimiento ordenarAscendente(int[] lista) que ordene el array in-place de forma ascendente.
    2. No utilices métodos de ordenación predefinidos de Java. Utiliza el algoritmo Bubble Sort (o cualquier otro de intercambio) basado únicamente en bucles anidados y una variable temporal para el intercambio.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define el procedimiento (void).
    2. Bucle Externo (Pasadas): Usa un bucle for (índice i) que controle el número de pasadas necesarias (length - 1 veces).
    3. Bucle Interno (Comparación y Intercambio): Anida un segundo bucle for (índice j) que recorra los elementos aún no ordenados (length - 1 - i veces).
    4. Condicional de Intercambio: Dentro del bucle interno, si lista[j] > lista[j+1]:
      • Realiza el intercambio de 3 pasos: temp = lista[j]; lista[j] = lista[j+1]; lista[j+1] = temp;.
    5. Comprobación (Trazas): Usa {3, 1, 2}. En la primera pasada, verifica que 3 y 1 se intercambien, dejando {1, 3, 2}.

    Concepto Clave:

    Se requieren dos bucles anidados y una variable temp para realizar el intercambio cuando lista[j] > lista[j+1].

    16) Contar Valores Distintos

    Objetivo:

    Contar la cantidad de valores únicos en un array sin usar estructuras auxiliares.

    Tarea a realizar:
    1. Implementa una función contarValoresUnicos(int[] lista) que devuelva la cantidad total de valores distintos en el array.
    2. Pista: Usa un bucle externo (i) que recorra todos los elementos. Dentro, usa un bucle interno (j < i) para verificar si el elemento actual (lista[i]) ya fue visto en una posición anterior.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Contador: Define la función (retorna int) e inicializa unicos = 0.
    2. Bucle Externo: Usa un bucle for (i) para iterar sobre cada elemento.
    3. Bandera de Duplicado: Inicializa boolean yaVisto = false dentro del bucle externo.
    4. Bucle Interno (Búsqueda hacia atrás): Usa un segundo bucle (j) que recorra las posiciones anteriores a i (desde 0 hasta i - 1).
    5. Activación de Bandera: Si lista[i] == lista[j], establece yaVisto = true y usa break para salir del bucle interno.
    6. Conteo Final: Después del bucle interno, si !yaVisto, incrementa unicos.
    7. Comprobación (Trazas): Usa {1, 2, 1}. En i=2 (valor 1), el bucle interno encuentra una coincidencia en j=0. yaVisto se vuelve true, y unicos no se incrementa, resultando en 2.

    Concepto Clave:

    Necesitas una bandera boolean yaVisto = false que se active en el bucle interno si se encuentra una coincidencia anterior. Solo incrementas el contador si la bandera es false al salir del bucle interno.

    17) Verificar Simetría (Palíndromo de Array)

    Objetivo:

    Implementar una verificación de palíndromo para un array de números.

    Tarea a realizar:
    1. Implementa una función esSimetrico(int[] lista) que devuelva true si el array se lee igual de izquierda a derecha que de derecha a izquierda.
    2. Pista: Utiliza la técnica de dos punteros (uno en el inicio y otro en el final) que se mueven hacia el centro del array en cada iteración del bucle while.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Punteros: Define la función (retorna boolean). Inicializa izquierdo = 0 y derecho = lista.length - 1.
    2. Bucle de Convergencia: Usa un bucle while (izquierdo < derecho).
    3. Condicional de Asimetría: Si lista[izquierdo] != lista[derecho], retorna false inmediatamente.
    4. Avance de Punteros: Incrementa izquierdo y decrementa derecho.
    5. Retorno de Éxito: Si el bucle finaliza, retorna true.
    6. Comprobación (Trazas): Usa {1, 2, 1}. I=0, D=2. Match. I=1, D=1. Loop termina. Retorna true.

    Concepto Clave:

    El bucle debe ser while (punteroIzquierdo < punteroDerecho). Si lista[izquierdo] != lista[derecho], retorna false.

    18) Detección de Suma Local Excesiva

    Objetivo:

    Implementar un patrón de "ventana deslizante" simple para verificar una condición localmente.

    Tarea a realizar:
    1. Implementa una función haySumaExcesiva(long[] datos, long limite) que devuelva true si en cualquier segmento consecutivo de cuatro elementos la suma supera el limite.
    2. Asegúrate de que tu bucle no intente acceder a índices fuera de los límites del array.
    Metodología: Divide y Vencerás
    1. Definición de Firma: Define la función que retorna boolean.
    2. Bucle de Ventana: Usa un bucle for (índice i) que recorra las posiciones de inicio válidas para una ventana de 4 elementos: i <= datos.length - 4.
    3. Cálculo de Suma Local: Dentro del bucle, calcula la suma de los 4 elementos consecutivos: suma = datos[i] + datos[i+1] + datos[i+2] + datos[i+3].
    4. Condicional y Retorno Temprano: Si suma > limite, retorna true.
    5. Retorno de Fracaso: Si el bucle finaliza, retorna false.
    6. Comprobación (Trazas): Usa {100, 10, 10, 10, 100} y limite=120. Verifica que el bucle para i=0 calcule 130, retorne true.

    Concepto Clave:

    El bucle principal (for i) debe terminar cuando queden menos de 4 elementos para la ventana: i <= datos.length - 4.

    19) Intercalar Elementos de Dos Arrays

    Objetivo:

    Combinar dos arrays en un tercero, alternando los elementos de ambos.

    Tarea a realizar:
    1. Implementa una función intercalar(int[] listaA, int[] listaB) que devuelva un nuevo array que contenga los elementos de listaA y listaB de forma alternada.
    2. El array resultante debe tener una longitud igual a la suma de las longitudes de A y B. Si una lista es más corta, se añaden los elementos restantes de la lista más larga.
    3. Pista: Utiliza un único bucle que se ejecute tantas veces como la longitud del array resultante. Dentro, usa if anidados para verificar si el índice actual es válido para A y B.
    Metodología: Divide y Vencerás
    1. Definición de Firma y Arrays: Define la función (retorna int[]). Crea int[] resultado con longitud A.length + B.length. Inicializa iA=0, iB=0.
    2. Bucle de Relleno: Usa un bucle for (iR) desde 0 hasta resultado.length - 1.
    3. Alternancia Condicional: Dentro del bucle, comprueba la posición y la disponibilidad de elementos:
      • Si iA < listaA.length Y (iB >= listaB.length O iR es par): Copia listaA[iA] a resultado[iR] y avanza iA.
      • Si no, copia listaB[iB] a resultado[iR] y avanza iB.
    4. Comprobación (Trazas): Usa A={1, 3}, B={2}. Verifica que en el índice 0 se copia A, en 1 se copia B, en 2 se copia A, dando {1, 2, 3}.

    Concepto Clave:

    El tamaño del nuevo array es listaA.length + listaB.length. Utiliza tres índices (iA, iB, iResultado) para controlar la posición en cada array.

    20) Encontrar Elementos Comunes en Arrays Ordenados

    Objetivo:

    Encontrar la intersección (elementos comunes) de dos arrays ordenados de la forma más eficiente.

    Tarea a realizar:
    1. Implementa una función encontrarInterseccion(int[] listaA, int[] listaB) que reciba dos arrays ordenados y devuelva un nuevo array conteniendo solo los valores que aparecen en ambos.
    2. Pista: Utiliza la técnica de dos punteros (uno para listaA y uno para listaB). Si los elementos son iguales, se añade al resultado y se avanzan ambos punteros. Si son diferentes, se avanza el puntero del valor menor.
    Metodología: Divide y Vencerás
    1. Definición de Punteros: Inicializa iA = 0, iB = 0. Crea un array temporal de tamaño máximo (min(A.length, B.length)) para almacenar coincidencias.
    2. Bucle de Punteros: Usa un bucle while (iA < listaA.length && iB < listaB.length).
    3. Lógica de Tres Vías: Dentro del while:
      • if (listaA[iA] < listaB[iB]): Avanza iA++.
      • else if (listaB[iB] < listaA[iA]): Avanza iB++.
      • else: (Coincidencia) Almacena el valor, avanza iA++ y iB++.
    4. Creación de Array Final: Crea el array final del tamaño exacto de las coincidencias encontradas en el temporal.
    5. Comprobación (Trazas): Usa A={10, 20}, B={5, 20}. Verifica que 5 (menor) hace avanzar iB. Luego 10 (menor) hace avanzar iA. Finalmente 20=20, se añade 20, y ambos avanzan, terminando con el resultado {20}.

    Concepto Clave:

    La eficiencia se logra utilizando un bucle while (i < listaA.length && j < listaB.length) y realizando solo una comparación y uno o dos avances por iteración.
