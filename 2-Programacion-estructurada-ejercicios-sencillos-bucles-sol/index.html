    🔵 Bloque 2: Bucles en Java

    📌 Sintaxis Básica

    // Bucle while
while (condicion) {
    // se ejecuta mientras la condición sea verdadera
}

// Bucle do-while (se ejecuta al menos una vez)
do {
    // código
} while (condicion);

// Bucle for clásico
for (int i = 0; i < n; i++) {
    // código
}

// Bucle for-each (recorrer arrays o colecciones)
for (tipo variable : array) {
    // código
}

    🚀 Ejercicios de Bucles

    1) Contar del 1 al N (while)

    Objetivo: Pedir un número N e imprimir del 1 hasta N usando while.

    Aplicación en el Mundo Real: Contador de iteraciones en procesos.

    VER Solución. 
    import java.util.Scanner;

public class ContarWhile {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce un número N: ");
        int n = scanner.nextInt();

        int i = 1;
        while (i <= n) {
            System.out.println(i);
            i++;
        }

        scanner.close();
    }
}

    2) Cuenta Regresiva (while)

    Objetivo: Pedir un número e imprimir la cuenta regresiva hasta 0.

    Aplicación en el Mundo Real: Temporizadores o countdown.

    VER Solución. 
    import java.util.Scanner;

public class CuentaRegresiva {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce un número inicial: ");
        int n = scanner.nextInt();

        while (n >= 0) {
            System.out.println(n);
            n--;
        }

        scanner.close();
    }
}

    3) Suma hasta N (while)

    Objetivo: Sumar todos los números del 1 al N.

    Aplicación en el Mundo Real: Calcular acumulados (ej: dinero ahorrado cada día).

    VER Solución. 
    import java.util.Scanner;

public class SumaHastaN {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce un número N: ");
        int n = scanner.nextInt();

        int suma = 0;
        int i = 1;

        while (i <= n) {
            suma += i;
            i++;
        }

        System.out.println("La suma es: " + suma);

        scanner.close();
    }
}

    4) Tabla de Multiplicar (for)

    Objetivo: Pedir un número y mostrar su tabla de multiplicar.

    Aplicación en el Mundo Real: Cálculos automáticos de productos.

    VER Solución. 
    import java.util.Scanner;

public class TablaMultiplicar {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce un número: ");
        int num = scanner.nextInt();

        for (int i = 1; i <= 10; i++) {
            System.out.println(num + " x " + i + " = " + (num * i));
        }

        scanner.close();
    }
}

    5) Factorial (for)

    Objetivo: Calcular el factorial de un número usando for.

    Aplicación en el Mundo Real: Cálculos matemáticos y probabilidades.

    VER Solución. 
    import java.util.Scanner;

public class Factorial {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce un número: ");
        int n = scanner.nextInt();

        int factorial = 1;
        for (int i = 1; i <= n; i++) {
            factorial *= i;
        }

        System.out.println("El factorial de " + n + " es " + factorial);

        scanner.close();
    }
}

    6) Contar Dígitos (do-while)

    Objetivo: Contar la cantidad de dígitos de un número.

    Aplicación en el Mundo Real: Validación de longitudes de números de cuenta, teléfono, etc.

    VER Solución. 
    import java.util.Scanner;

public class ContarDigitos {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce un número: ");
        int num = scanner.nextInt();

        int contador = 0;

        do {
            num /= 10;
            contador++;
        } while (num > 0);

        System.out.println("Cantidad de dígitos: " + contador);

        scanner.close();
    }
}

    7) Suma de Pares e Impares (for)

    Objetivo: Calcular por separado la suma de números pares e impares hasta N.

    Aplicación en el Mundo Real: Estadísticas de datos numéricos.

    VER Solución. 
    import java.util.Scanner;

public class SumaParesImpares {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce un número N: ");
        int n = scanner.nextInt();

        int sumaPares = 0;
        int sumaImpares = 0;

        for (int i = 1; i <= n; i++) {
            if (i % 2 == 0) sumaPares += i;
            else sumaImpares += i;
        }

        System.out.println("Suma de pares: " + sumaPares);
        System.out.println("Suma de impares: " + sumaImpares);

        scanner.close();
    }
}

    8) Recorrer un Array (for-each)

    Objetivo: Leer un array de números y mostrarlos con for-each.

    Aplicación en el Mundo Real: Procesar listas de datos.

    VER Solución. 
    import java.util.Scanner;

public class RecorrerArray {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int[] numeros = new int[5];
        System.out.println("Introduce 5 números:");

        for (int i = 0; i < numeros.length; i++) {
            numeros[i] = scanner.nextInt();
        }

        System.out.println("Números introducidos:");
        for (int n : numeros) {
            System.out.println(n);
        }

        scanner.close();
    }
}

    9) Buscar en un Array (for-each)

    Objetivo: Buscar si un número está en un array.

    Aplicación en el Mundo Real: Validar si un dato existe en un registro.

    VER Solución. 
    import java.util.Scanner;

public class BuscarArray {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int[] numeros = {10, 20, 30, 40, 50};

        System.out.print("Introduce un número a buscar: ");
        int buscado = scanner.nextInt();

        boolean encontrado = false;

        for (int n : numeros) {
            if (n == buscado) {
                encontrado = true;
                break;
            }
        }

        if (encontrado) {
            System.out.println("Número encontrado en el array.");
        } else {
            System.out.println("Número no encontrado.");
        }

        scanner.close();
    }
}

    10) Pirámide de Asteriscos (for anidado)

    Objetivo: Dibujar una pirámide de asteriscos con bucles anidados.

    Aplicación en el Mundo Real: Representaciones gráficas por consola.

    VER Solución. 
    import java.util.Scanner;

public class PiramideAsteriscos {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Introduce el número de filas: ");
        int filas = scanner.nextInt();

        for (int i = 1; i <= filas; i++) {
            for (int j = 1; j <= i; j++) {
                System.out.print("*");
            }
            System.out.println();
        }

        scanner.close();
    }
}
