    Ejercicios de Bucles y Condicionales en Java

    Nivel PADAWAN (1 - 10)

    Ejercicios centrados en bucles simples (for, while) y el uso básico de if/else.

    Ejercicio 1: Múltiplos Fijos

    Enunciado: Realiza un programa que muestre por pantalla los 15 primeros múltiplos del número 3 (3, 6, 9, ..., 45).

    Metodología: Divide y Vencerás
    1. Conteo (Bucle): Necesitas una estructura que repita una acción exactamente 15 veces. Utiliza un bucle for inicializado en 1 y que se ejecute hasta 15.
      • Comprobación (Trazas): Verifica que el contador i comience en 1 y termine en 15.
    2. Cálculo (Aritmética): Dentro del bucle, calcula el múltiplo multiplicando el contador i por 3.
      • Comprobación (Trazas): Para i=1, el resultado debe ser 3. Para i=5, debe ser 15.
    3. Visualización: Imprime el resultado en cada iteración.

    Contexto de Aplicación:

    Secuencias de identificación automática o generación de códigos de inventario (SKUs) siguiendo un patrón fijo.

    Ejercicio 2: Suma Simple

    Enunciado: Realiza un programa que calcule y muestre la suma de todos los números enteros comprendidos entre 1 y 100.

    Metodología: Divide y Vencerás
    1. Acumulador (Inicialización): Declara una variable suma fuera del bucle e inicialízala a 0. Este será tu acumulador.
      • Comprobación (Trazas): Verifica que antes del bucle, suma sea 0.
    2. Iteración (Bucle): Crea un bucle for que recorra los números desde 1 hasta 100.
    3. Acumulación (Proceso): Dentro del bucle, actualiza el valor del acumulador sumándole el número actual (suma = suma + i).
      • Comprobación (Trazas): Si en la iteración 5, suma vale 10 (1+2+3+4), después de la suma, suma debe valer 15.
    4. Resultado: Muestra el valor final de la suma fuera del bucle.

    Contexto de Aplicación:

    Cálculo de intereses compuestos o deudas acumuladas a lo largo de un período de tiempo.

    Ejercicio 3: Encontrando el Máximo

    Enunciado: Pide al usuario que introduzca 5 números enteros por teclado y, al finalizar, muestra cuál de ellos fue el número mayor.

    Metodología: Divide y Vencerás
    1. Inicialización del Máximo: Declara una variable maximo e inicialízala con un valor muy pequeño (o el primer número leído) para garantizar que cualquier otro número sea mayor que él inicialmente.
      • Comprobación (Trazas): Si inicializas con el primer input, verifica que después de la primera lectura, maximo es igual al input.
    2. Bucle y Lectura: Usa un bucle for para repetir la lectura de input 5 veces.
    3. Comparación (Condicional): Dentro del bucle, usa una sentencia if para comparar el número recién leído con el maximo actual. Si el nuevo número es mayor, actualiza maximo.
      • Comprobación (Trazas): Simula la entrada {10, 5, 20}. Después de leer 20, verifica que maximo se actualice de 10 a 20.
    4. Salida: Muestra el valor final de maximo.

    Contexto de Aplicación:

    Determinar la venta máxima o el pico de tráfico en un registro diario de datos.

    Ejercicio 4: Conteo Dinámico

    Enunciado: Pide al usuario un número entero positivo $N$ y muestra por pantalla todos los números desde el 1 hasta $N$.

    Metodología: Divide y Vencerás
    1. Lectura: Lee el número $N$ desde el teclado.
    2. Bucle Dinámico: Utiliza un bucle while o for. Si usas while, debes inicializar una variable de conteo (i = 1) y la condición debe ser i <= N.
    3. Proceso: Dentro del bucle, imprime el valor actual del contador y asegúrate de incrementarlo al final de cada iteración.
      • Comprobación (Trazas): Si $N=4$, verifica que el bucle imprima 1, 2, 3, 4 y luego termine.

    Contexto de Aplicación:

    Implementación de barras de progreso o conteo de tareas pendientes en un sistema operativo.

    Ejercicio 5: Bucle Centinela Simple

    Enunciado: Realiza un programa que continúe pidiendo números enteros por teclado hasta que el usuario introduzca el número 0 (cero).

    Metodología: Divide y Vencerás
    1. Lectura Inicial: Lee el primer número antes de entrar al bucle. Este actuará como valor inicial para la condición.
    2. Bucle de Control (while): Define el bucle while cuya condición de permanencia sea que el número leído sea diferente de 0.
    3. Proceso Continuo: Dentro del bucle, realiza cualquier acción deseada (o simplemente imprime el número) y, crucialmente, vuelve a leer un nuevo número al final para actualizar la condición del while.
      • Comprobación (Trazas): Simula la entrada {5, 1, -8, 0}. El bucle debe ejecutarse 3 veces antes de fallar la condición al leer el 0.

    Contexto de Aplicación:

    Terminales de procesamiento continuo o interfaces de línea de comandos donde el comando de salida es una palabra clave o un valor específico.

    Ejercicio 6: Conteo Regresivo

    Enunciado: Muestra por pantalla la cuenta regresiva desde 50 hasta 1 (ambos inclusive).

    Metodología: Divide y Vencerás
    1. Bucle Decremental: Usa un bucle for con una inicialización alta (i = 50), una condición de parada baja (i >= 1) y un operador de decremento (i--).
      • Comprobación (Trazas): Verifica que el valor inicial sea 50, que en la siguiente iteración sea 49, y que el bucle no se ejecute cuando i sea 0.
    2. Visualización: Imprime el valor de i en cada paso.

    Contexto de Aplicación:

    Sistemas de control de misiones para lanzamientos o temporizadores de seguridad.

    Ejercicio 7: Cálculo de Media

    Enunciado: Pide al usuario que introduzca 4 notas por teclado y, al finalizar la lectura, calcula y muestra la media aritmética de dichas notas.

    Metodología: Divide y Vencerás
    1. Variables de Control: Declara un acumulador suma = 0 y utiliza un contador i.
    2. Bucle: Usa un bucle for de 4 iteraciones para leer las 4 notas.
    3. Acumulación: Dentro del bucle, suma cada nota leída al acumulador suma.
    4. Cálculo Final (División): Después de que el bucle termine, calcula la media dividiendo la suma entre el número de notas (4). Es crucial que esta división se realice usando tipos de punto flotante (double) para obtener un resultado preciso.
      • Comprobación (Trazas): Simula la entrada {10, 5, 5, 0}. La suma debe ser 20. La media final debe ser $20.0 / 4 = 5.0$.

    Contexto de Aplicación:

    Sistemas académicos o de recursos humanos para calcular el rendimiento promedio de un empleado o un estudiante.

    Ejercicio 8: Filtrado Condicional

    Enunciado: Muestra todos los números enteros impares comprendidos entre 1 y 50.

    Metodología: Divide y Vencerás
    1. Bucle de Recorrido: Implementa un bucle for que itere por todos los números desde 1 hasta 50.
    2. Filtro (Condicional): Dentro del bucle, utiliza la operación módulo (%) para determinar si el número actual es impar. Un número es impar si su residuo al dividirlo entre 2 es diferente de 0. (if (i % 2 != 0)).
    3. Salida: Solo imprime el número i si pasa la condición del paso 2.
      • Comprobación (Trazas): Verifica que para i=4 no se imprima nada, y para i=5 sí se imprima.

    Contexto de Aplicación:

    Filtrado de datos en un dataset donde solo se requieren los registros que cumplen ciertas condiciones matemáticas (ej. IDs de cliente con terminación impar).

    Ejercicio 9: Intentos Limitados

    Enunciado: Pide al usuario introducir un PIN secreto de 4 dígitos. El usuario tiene un máximo de 3 intentos para acertar. Si acierta, el programa termina con éxito; si falla los 3, el programa termina bloqueado.

    Metodología: Divide y Vencerás
    1. Definición de Constante: Declara la constante del PIN_CORRECTO.
    2. Bucle de Intentos: Implementa un bucle for o while que limite las iteraciones a 3. Usa una variable intentos.
    3. Condición de Éxito y Ruptura: Dentro del bucle, después de leer el PIN, utiliza un if para verificar si el input coincide con el PIN_CORRECTO. Si acierta, imprime el mensaje de éxito y utiliza la sentencia break para salir inmediatamente del bucle.
      • Comprobación (Trazas): Si acierta en el intento 2, verifica que el bucle se detenga y no se ejecute la tercera iteración.
    4. Control de Bloqueo: Fuera del bucle, verifica si el bucle terminó por el break (éxito) o porque se agotaron los 3 intentos.

    Contexto de Aplicación:

    Sistemas de seguridad, cajeros automáticos o pasarelas de pago con límite de fallos para evitar ataques de fuerza bruta.

    Ejercicio 10: Clasificación Simple

    Enunciado: Lee un número entero por teclado y, mediante sentencias condicionales, clasifícalo e imprime si es positivo, negativo o cero.

    Metodología: Divide y Vencerás
    1. Lectura: Lee el número $N$.
    2. Condicional Principal: Utiliza la estructura if-else if-else. La primera condición debe ser if (N > 0).
    3. Segunda Condición: La siguiente debe ser else if (N < 0).
    4. Caso Residual: El bloque else final manejará automáticamente el caso restante (cero).
      • Comprobación (Trazas): Prueba la traza con $N=10$, $N=-5$ y $N=0$ para asegurar que solo se ejecute un bloque de código por entrada.

    Contexto de Aplicación:

    Clasificación básica de métricas o indicadores (ej. si la ganancia es positiva, negativa o nula).

    Nivel JEDI (11 - 20)

    Ejercicios que requieren el uso de acumuladores complejos, bucles anidados, validación de entrada o el uso de flags (banderas booleanas).

    Ejercicio 11: Factorial

    Enunciado: Realiza un programa que lea un número entero positivo $N$ y calcule y visualice su factorial $N!$.

    Metodología: Divide y Vencerás
    1. Validación: Utiliza un bucle while o if para asegurar que el número $N$ leído sea positivo (o cero, ya que $0! = 1$).
    2. Inicialización: Declara un acumulador factorial e inicialízalo a 1 (ya que la multiplicación por 0 arruinaría el cálculo).
    3. Iteración Decremental: Usa un bucle while o for que vaya desde $N$ hasta 1.
    4. Acumulación Multiplicativa: Dentro del bucle, multiplica el acumulador por el contador actual (factorial = factorial * i).
      • Comprobación (Trazas): Simula $N=4$.
        • Inicio: factorial = 1.
        • Iteración 1 (i=4): factorial es $1 \times 4 = 4$.
        • Iteración 2 (i=3): factorial es $4 \times 3 = 12$.
        • Iteración 3 (i=2): factorial es $12 \times 2 = 24$.
        • Iteración 4 (i=1): factorial es $24 \times 1 = 24$.

    Contexto de Aplicación:

    Algoritmos de probabilidad, combinatoria o en simulaciones físicas.

    Ejercicio 12: Detección con Bandera (Flag)

    Enunciado: Pide al usuario que introduzca 10 números enteros por teclado. Al finalizar la lectura, informa si al menos uno de los números introducidos fue negativo. Debes usar una variable booleana para registrar el evento.

    Metodología: Divide y Vencerás
    1. Inicialización de Bandera: Declara una variable boolean llamada hayNegativo e inicialízala a false.
      • Comprobación (Trazas): hayNegativo = false al inicio.
    2. Bucle de Lectura: Usa un bucle for para leer exactamente 10 números.
    3. Activación de Bandera: Dentro del bucle, si el número leído es negativo, establece hayNegativo = true.
    4. Terminación Temprana (Opcional): Una vez que la bandera sea true, puedes usar break para terminar el bucle anticipadamente, ya que la condición ya se ha cumplido.
    5. Resultado Final: Después del bucle, usa un if para imprimir el mensaje apropiado basado en el estado final de la variable hayNegativo.

    Contexto de Aplicación:

    Sistemas de monitoreo industrial o meteorológico que necesitan alertar (activar una alarma) si se detecta un valor fuera de un rango seguro, sin importar cuántos valores más se lean.

    Ejercicio 13: Conteo Doble

    Enunciado: Pide al usuario que introduzca 10 números no nulos por teclado y, al finalizar, muestra cuántos de ellos fueron positivos y cuántos fueron negativos.

    Metodología: Divide y Vencerás
    1. Acumuladores Duales: Declara dos contadores, conteoPositivos = 0 y conteoNegativos = 0.
    2. Bucle Fijo: Usa un bucle for para iterar 10 veces.
    3. Condicionales Anidadas: Dentro del bucle, lee el número $N$. Utiliza una estructura if/else if:
      • if (N > 0): incrementa conteoPositivos.
      • else if (N < 0): incrementa conteoNegativos.
    4. Salida: Muestra los valores finales de ambos contadores.
      • Comprobación (Trazas): Simula la entrada {-5, 10, -10}. Al final, conteoPositivos debe ser 1 y conteoNegativos debe ser 2.

    Contexto de Aplicación:

    Análisis de tendencias o resultados electorales (votos a favor vs. votos en contra) o análisis de transacciones financieras (créditos vs. débitos).

    Ejercicio 14: Tablas de Multiplicar (Anidamiento Básico)

    Enunciado: Muestra por pantalla las tablas de multiplicar completas del 1 al 10, utilizando un bucle anidado.

    Metodología: Divide y Vencerás
    1. Bucle Externo (Tabla): El bucle for externo debe controlar qué tabla se está calculando (de $i=1$ a $i=10$).
      • Comprobación (Trazas): Asegura que el bucle externo se ejecuta 10 veces.
    2. Bucle Interno (Multiplicador): Dentro del bucle externo, implementa un segundo bucle for que controle por qué número se está multiplicando (de $j=1$ a $j=10$).
      • Comprobación (Trazas): Para $i=2$, verifica que el bucle interno ejecute $2 \times 1, 2 \times 2, \dots, 2 \times 10$.
    3. Cálculo y Salida: Dentro del bucle interno, realiza e imprime el resultado de $i \times j$. Asegúrate de imprimir un salto de línea después de que termine cada tabla (al final del bucle externo).

    Contexto de Aplicación:

    Generación de matrices o datasets tabulares en programación de reportes.

    Ejercicio 15: Acumulación Condicional Dual

    Enunciado: Lee una secuencia de números por teclado. La lectura termina cuando el usuario introduce -1. Al finalizar, muestra por separado el producto de todos los números pares leídos y la suma de todos los números impares leídos.

    Metodología: Divide y Vencerás
    1. Inicialización Dual: Inicializa dos acumuladores: productoPares = 1 y sumaImpares = 0. (El producto debe ser 1, no 0, para no anular la multiplicación).
    2. Bucle Centinela (while): Usa un bucle while que permanezca activo mientras el input no sea -1.
    3. Condicional Múltiple: Dentro del bucle, después de leer el número $N$:
      • Usa un if para determinar si $N$ es par (usando % 2 == 0). Si lo es, aplica productoPares *= N.
      • Usa un else para el caso impar. Si lo es, aplica sumaImpares += N.
    4. Lectura Continua: No olvides leer el siguiente número al final del while.

    Contexto de Aplicación:

    Procesamiento de lotes de datos donde diferentes tipos de transacciones (pares e impares) deben ser gestionadas por sistemas distintos (ej. acumular impuestos y multiplicar cantidades).

    Ejercicio 16: Login con do-while

    Enunciado: Simula un sistema de login. Pide un usuario y una clave. El usuario tiene un máximo de 3 intentos. Utiliza el bucle do-while para asegurar que el proceso de verificación se ejecute al menos una vez.

    Metodología: Divide y Vencerás
    1. Constantes: Define las credenciales correctas.
    2. Contadores y Banderas: Inicializa intentos = 0 y accesoExitoso = false.
    3. Estructura do-while: Implementa el do-while. El cuerpo del do debe leer las credenciales e incrementar intentos.
    4. Verificación: Dentro del do, utiliza un if para comparar las credenciales. Si son correctas, establece accesoExitoso = true.
    5. Condición del while: La condición debe ser while (intentos < 3 && !accesoExitoso).
      • Comprobación (Trazas): Si falla dos veces, en la tercera iteración intentos es 3 y el bucle termina, independientemente del resultado. Si acierta en el primer intento, el bucle debe parar inmediatamente.

    Contexto de Aplicación:

    Sistemas de autenticación donde la validación de la lógica es crítica y debe ejecutarse al menos una vez (ej. cajeros automáticos, inicio de sesión).

    Ejercicio 17: Horas Extra (Condicional de Cálculo)

    Enunciado: Pide al usuario las horas trabajadas en una semana. Si ha trabajado más de 40 horas, las horas excedentes se pagan con un factor de 1.5. Calcula y muestra el salario total, asumiendo una tarifa base de 10 €/hora.

    Metodología: Divide y Vencerás
    1. Constante: Define la TARIFA_BASE = 10 y el LIMITE_HORAS = 40.
    2. Lectura: Lee las horasTrabajadas.
    3. Lógica Condicional: Utiliza if/else para determinar el cálculo del salario:
      • if (horasTrabajadas > LIMITE_HORAS): Calcula el salario base (40 * 10) y luego el salario extra ((horasTrabajadas - 40) * 10 * 1.5). Súmalos.
      • else: El salario es simplemente horasTrabajadas * 10.
    4. Trazas: Simula 50 horas trabajadas:
      • Salario base: $40 \times 10 = 400$.
      • Horas extra: $50 - 40 = 10$.
      • Salario extra: $10 \times 10 \times 1.5 = 150$.
      • Total: $400 + 150 = 550$.

    Contexto de Aplicación:

    Programación de nóminas y cálculos complejos basados en tarifas y umbrales.

    Ejercicio 18: Recorrido ASCII

    Enunciado: Muestra todas las letras mayúsculas del alfabeto (de A a Z) utilizando un bucle for que trabaje con el tipo de dato char.

    Metodología: Divide y Vencerás
    1. Inicialización char: Inicializa el bucle for con una variable de tipo char que comience en el carácter 'A'.
    2. Condición char: La condición debe ser que el carácter sea menor o igual al carácter 'Z'.
    3. Incremento: Utiliza el incremento normal (++) sobre la variable char. Java interpreta esto sumando 1 a su código ASCII y mostrando el siguiente carácter.
      • Comprobación (Trazas): El bucle debe comenzar con 'A', luego pasar a 'B', 'C', y así sucesivamente.
    4. Visualización: Imprime la letra en cada iteración.

    Contexto de Aplicación:

    Generación de identificadores alfanuméricos, secuencias de columnas en hojas de cálculo o procesamiento de caracteres en sistemas de archivos.

    Ejercicio 19: Validación de Rango

    Enunciado: Pide una edad al usuario. Usa un bucle while para forzar a que el usuario introduzca una edad válida (entre 1 y 120). Una vez obtenida la edad válida, indica si la persona puede votar (>= 18) y, si no puede, cuántos años le faltan.

    Metodología: Divide y Vencerás
    1. Bucle de Validación (do-while): Utiliza un do-while para asegurar que la lectura se realice al menos una vez. La condición del while debe ser (edad < 1 || edad > 120).
      • Comprobación (Trazas): Si el usuario ingresa 0, el bucle debe repetirse. Si ingresa 25, el bucle debe terminar.
    2. Condicional de Voto: Después del bucle (con una edad válida garantizada), utiliza un if/else:
      • if (edad >= 18): mensaje de puede votar.
      • else: calcular la diferencia 18 - edad y mostrar el resultado.

    Contexto de Aplicación:

    Cualquier formulario de registro en línea que deba asegurar que los datos introducidos cumplen con criterios de rango específicos antes de continuar.

    Ejercicio 20: Detector de Números Primos

    Enunciado: Lee un número entero $N$ por teclado y determina si es un número primo (solo divisible por 1 y por sí mismo).

    Metodología: Divide y Vencerás
    1. Pre-condiciones: Usa un if para manejar los casos especiales 0, 1 y números negativos (que no son primos).
    2. Bandera: Inicializa la bandera esPrimo = true.
    3. Bucle de Prueba: Para probar la divisibilidad de $N$, solo necesitas verificar hasta la raíz cuadrada de $N$, o de forma más sencilla, hasta $N/2$. Usa un bucle for que vaya desde $i=2$ hasta $N/2$.
    4. Detección de Divisor: Dentro del bucle, usa un if con la operación módulo: if (N % i == 0). Si se cumple, significa que has encontrado un divisor; por lo tanto, establece esPrimo = false y usa break para detener el bucle (ya no necesitas buscar más).
      • Comprobación (Trazas): Simula $N=9$.
        • i=2: $9\%2 \ne 0$.
        • i=3: $9\%3 = 0$. ¡Falso! esPrimo = false. break.
    5. Resultado Final: Imprime el resultado basándote en el valor final de esPrimo.

    Contexto de Aplicación:

    Criptografía y algoritmos de seguridad (como RSA), que dependen de la generación y verificación de números primos muy grandes.

    Nivel MAESTRO JEDI (21 - 30)

    Ejercicios que combinan múltiples estructuras de control, patrones de diseño o la implementación de algoritmos más complejos.

    Ejercicio 21: Simulación con Aleatoriedad

    Enunciado: Simula el lanzamiento de dos dados estándar (6 caras) 10 veces. Cuenta y muestra cuántas veces la suma de los dos dados fue exactamente 7. (Debes usar Math.random() para la simulación).

    Metodología: Divide y Vencerás
    1. Contador: Inicializa conteoSietes = 0.
    2. Bucle de Lanzamiento: Usa un bucle for que se repita 10 veces (los 10 lanzamientos).
    3. Generación Aleatoria: Dentro del bucle, genera dos números aleatorios enteros entre 1 y 6 (dado 1 y dado 2).
    4. Condición de Éxito: Usa un if para verificar la suma: if (dado1 + dado2 == 7). Si se cumple, incrementa conteoSietes.
      • Comprobación (Trazas): Simula un caso donde el lanzamiento 3 da (3, 4) y el lanzamiento 5 da (6, 1). Verifica que conteoSietes sea 2 después del lanzamiento 5.
    5. Resultado: Muestra el conteoSietes al final.

    Contexto de Aplicación:

    Simulación Monte Carlo, modelado de riesgos o estadística aplicada en el desarrollo de videojuegos y sistemas de lotería.

    Ejercicio 22: Potencia sin Operador Nativo

    Enunciado: Realiza un programa que calcule el valor $A^B$ (A elevado a B) sin utilizar el operador de potencia nativo ni la función Math.pow(). Los valores $A$ (base) y $B$ (exponente, positivo) son introducidos por teclado.

    Metodología: Divide y Vencerás
    1. Lectura y Validación: Lee $A$ y $B$. Asegura que $B$ sea $\ge 0$.

    3. Bucle de Multiplicación: Usa un bucle for que se ejecute $B$ veces.
    4. Acumulación: Dentro del bucle, la operación a realizar es resultado = resultado * A.
      • Comprobación (Trazas): Simula $A=2, B=3$.
        • Inicio: resultado = 1.

        • Iteración 2: `resultado = 2 * 2 = 4$.
        • Iteración 3: `resultado = 4 * 2 = 8$.

    Ejercicio 27: Inversión de Números

    Enunciado: Pide al usuario un número entero. Invierte el orden de sus dígitos (ej. 1234 se convierte en 4321) y muestra el número invertido.

    Metodología: Divide y Vencerás
    1. Variables: Inicializa invertido = 0. Trabaja con el número original N.
    2. Bucle de Descomposición: Usa un bucle while que se ejecute mientras $N$ sea mayor que 0.
    3. Extracción de Dígito: Dentro del bucle, el último dígito se obtiene con la operación módulo: digito = N % 10.
    4. Acumulación Inversa: Actualiza el número invertido multiplicando por 10 y sumando el dígito: invertido = (invertido * 10) + digito.
    5. Recorte de Número: Elimina el último dígito del número original: N = N / 10.
      • Comprobación (Trazas): Simula $N=123$.
        • Iteración 1: digito=3. invertido=3. N=12.
        • Iteración 2: digito=2. invertido=32. N=1.
        • Iteración 3: digito=1. invertido=321. N=0. Fin.

    Contexto de Aplicación:

    Verificación de palíndromos numéricos o la manipulación de números de serie y códigos de identificación en formato inverso.

    Ejercicio 28: Adivinanza Binaria

    Enunciado: El usuario "piensa" un número entre 1 y 100. El programa debe intentar adivinarlo haciendo preguntas. El usuario solo puede responder si el número es "M" (mayor), "m" (menor) o "I" (igual). El programa debe usar una búsqueda binaria simple para optimizar los intentos.

    Metodología: Divide y Vencerás
    1. Límites: Inicializa min = 1 y max = 100.
    2. Bucle de Búsqueda: Usa un bucle while que se ejecute mientras no se haya adivinado el número.
    3. Cálculo del Intento: Calcula el punto medio (la hipótesis): intento = (min + max) / 2.
    4. Respuesta del Usuario: Lee la respuesta del usuario (M, m, I).
    5. Ajuste de Límites (Condicional): Utiliza if/else if:
      • if (respuesta == 'I'): Éxito. Usar break.
      • else if (respuesta == 'M'): El número está en la mitad superior. max = intento - 1.
      • else if (respuesta == 'm'): El número está en la mitad inferior. min = intento + 1.
      • Comprobación (Trazas): Si el número pensado es 60.
        • Intento 1: (1+100)/2 = 50. Usuario dice 'm'. min se convierte en 51.
        • Intento 2: (51+100)/2 = 75. Usuario dice 'M'. max se convierte en 74.

    Contexto de Aplicación:

    Algoritmos de búsqueda binaria en bases de datos, que es la forma más eficiente de encontrar un registro en una lista ordenada.

    Ejercicio 29: Optimización de Billetes

    Enunciado: Dada una cantidad $C$ de euros (múltiplo de 5), calcula y muestra la cantidad mínima de billetes de 500, 200, 100, 50, 20, 10 y 5 € necesarios para cubrir dicha cantidad.

    Metodología: Divide y Vencerás
    1. array de Billetes: Define un conjunto de valores (array conceptualmente) de billetes ordenados de mayor a menor: ${500, 200, 100, 50, 20, 10, 5}$.
    2. Bucle por Tipo de Billete: Usa un bucle for que recorra este conjunto de billetes, del más grande al más pequeño.
    3. Cálculo de Cantidad: Para cada billete, calcula cuántos billetes de ese tipo caben en la cantidad restante: cantidad = C / billeteActual.
    4. Impresión y Restante: Si cantidad > 0, imprime el resultado. Luego, recalcula la cantidad restante para la siguiente iteración: C = C % billeteActual.
      • Comprobación (Trazas): Simula $C=785$.
        • Billete 500: 785/500 = 1. Restante: $785\%500 = 285$.
        • Billete 200: 285/200 = 1. Restante: $285\%200 = 85$.
        • Billete 100: `85/100 = 0$.
        • ...
        • Billete 50: `85/50 = 1$. Restante: $85\%50 = 35$.

    Contexto de Aplicación:

    Ejercicio 30: Números Perfectos

    Enunciado: Pide un número entero $N$ al usuario y determina si es un Número Perfecto. Un número perfecto es aquel cuya suma de sus divisores propios (excluyendo el propio número) es igual al número. (Ejemplo: $6 = 1 + 2 + 3$).

    Metodología: Divide y Vencerás
    1. Validación y Acumulador: Asegura que $N > 0$. Inicializa sumaDivisores = 0.
    2. Bucle de Divisores: Usa un bucle for que recorra todos los números desde $i=1$ hasta $N-1$ (divisores propios).
    3. Condición de Divisor: Dentro del bucle, usa un if para verificar si $i$ es un divisor de $N$: if (N % i == 0).
    4. Acumulación: Si la condición se cumple, suma $i$ al acumulador sumaDivisores.
      • Comprobación (Trazas): Simula $N=6$.
        • $i=1$: $6\%1=0$. `sumaDivisores = 1$.
        • $i=2$: $6\%2=0$. `sumaDivisores = 1+2=3$.
        • $i=3$: $6\%3=0$. `sumaDivisores = 3+3=6$.
        • $i=4$: $6\%4 \ne 0$.
        • $i=5$: $6\%5 \ne 0$.
    5. Resultado Final: Después del bucle, compara: if (sumaDivisores == N).

    Contexto de Aplicación:

    Investigación en la teoría de números, que tiene aplicaciones en criptografía y análisis de algoritmos computacionales.
