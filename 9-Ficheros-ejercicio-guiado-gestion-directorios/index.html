    Ejercicio Guiado: Gestión de Ficheros y Directorios con java.nio

    1. Introducción al problema

    Imagina que trabajas en una pequeña empresa que necesita organizar sus documentos digitales. Cada día se generan archivos (informes, facturas, notas...) y es importante poder gestionar carpetas y ficheros de forma sencilla desde un programa.

    En este ejercicio vas a desarrollar una aplicación en Java que permita gestionar directorios y ficheros desde consola. Aprenderás a crear carpetas, listar su contenido, crear archivos y eliminarlos.

    Para ello utilizaremos la API moderna de Java NIO.2 (java.nio.file), que ofrece clases como Path y Files con un diseño más limpio, seguro y expresivo que la antigua clase File de java.io.

    ¿Por qué java.nio en vez de java.io?

    La API java.nio.file (introducida en Java 7) reemplaza y mejora a java.io.File en varios aspectos:

    • Excepciones claras: los métodos de Files lanzan IOException con mensajes descriptivos en lugar de devolver false silenciosamente cuando algo falla.
    • Inmutabilidad: Path es inmutable, lo que evita bugs por modificación accidental de rutas.
    • Más funcionalidad: operaciones atómicas, enlaces simbólicos, atributos extendidos, recorrido de árboles de directorios, etc.
    • Integración con Streams: métodos como Files.list() devuelven Stream<Path>, perfectos para programación funcional.

    2. Conceptos básicos de java.nio.file

    Antes de empezar a programar, repasemos las clases principales que utilizaremos:

    2.1 Path — Representar rutas

    Path es una interfaz que representa una ruta en el sistema de archivos. Se crea con el método estático Path.of(...):

    import java.nio.file.Path;

Path carpeta = Path.of("datos");
Path fichero = Path.of("datos", "informe.txt");

    Equivalencia con java.io

    java.io (antiguo) java.nio.file (moderno)
    new File("datos") Path.of("datos")
    new File(base, "informe.txt") base.resolve("informe.txt")
    fichero.getName() path.getFileName()
    fichero.getAbsolutePath() path.toAbsolutePath()

    2.2 Files — Operar sobre rutas

    Files es una clase de utilidad con métodos estáticos para crear, eliminar, listar y consultar ficheros y directorios:

    import java.nio.file.Files;

Files.createDirectories(path);   // Crea el directorio (y padres si faltan)
Files.createFile(path);          // Crea un fichero vacío
Files.delete(path);              // Elimina fichero o directorio vacío
Files.exists(path);              // Comprueba si existe
Files.isDirectory(path);         // Comprueba si es directorio
Files.isRegularFile(path);       // Comprueba si es fichero regular

    Diferencia clave con java.io

    Con java.io.File, métodos como mkdir() o delete() devuelven true o false sin explicar qué falló. Con java.nio.file.Files, si algo va mal se lanza una excepción (NoSuchFileException, DirectoryNotEmptyException, FileAlreadyExistsException...) con información precisa del problema.

    2.3 DirectoryStream y Files.list() — Listar contenido

    Para listar el contenido de un directorio hay dos enfoques principales:

    // Opción A: DirectoryStream (bajo nivel, try-with-resources)
try (DirectoryStream<Path> stream = Files.newDirectoryStream(dir)) {
    for (Path entry : stream) {
        System.out.println(entry.getFileName());
    }
}

// Opción B: Files.list() con Stream funcional
try (Stream<Path> stream = Files.list(dir)) {
    stream.forEach(entry -> System.out.println(entry.getFileName()));
}

    Tip

    Files.list() devuelve un Stream<Path> que debe cerrarse (por eso se usa try-with-resources). Esto es diferente a los Streams de colecciones, que no necesitan cerrarse.

    3. Enunciado del ejercicio

    Desarrolla un programa en Java que muestre un menú por consola y permita al usuario gestionar ficheros y directorios dentro de una carpeta base llamada datos.

    El menú debe permitir:

    1. Crear directorio
    2. Crear fichero
    3. Listar contenido de un directorio
    4. Eliminar fichero o directorio
    5. Salir

    4. Ayudas paso a paso

    4.1 Crear la carpeta base

    Lo primero que debe hacer el programa es asegurar que existe la carpeta datos. Usamos Files.createDirectories() que crea la carpeta y todos los directorios padres que falten. Si ya existe, no hace nada (a diferencia de Files.createDirectory(), que lanzaría excepción).

    Path base = Path.of("datos");
if (Files.notExists(base)) {
    Files.createDirectories(base);
}

    ¿Por qué createDirectories y no createDirectory?

    • Files.createDirectory(path) → crea solo el último directorio. Falla si el padre no existe o si ya existe el directorio.
    • Files.createDirectories(path) → crea toda la cadena de directorios que falten. No falla si ya existe. Es la opción más segura para inicialización.

    4.2 Crear un directorio dentro de la base

    Para crear un subdirectorio usamos resolve() sobre la ruta base. Este método concatena la ruta del padre con el nombre del hijo:

    System.out.print("Nombre del directorio: ");
String nombre = sc.nextLine();
Path dir = base.resolve(nombre);
Files.createDirectories(dir);
System.out.println("Directorio creado: " + dir.toAbsolutePath());

    El método resolve()

    resolve() es el equivalente NIO de new File(padre, hijo). Construye una nueva ruta combinando la ruta base con el nombre o ruta relativa que le pases. Por ejemplo: Path.of("datos").resolve("informes") produce datos/informes.

    4.3 Crear un fichero vacío

    Para crear un fichero usamos Files.createFile(). Es importante comprobar primero si ya existe, porque este método lanza FileAlreadyExistsException si el fichero ya está creado:

    System.out.print("Nombre del fichero: ");
String nombre = sc.nextLine();
Path fichero = base.resolve(nombre);
if (Files.exists(fichero)) {
    System.out.println("El fichero ya existe.");
} else {
    Files.createFile(fichero);
    System.out.println("Fichero creado: " + fichero.toAbsolutePath());
}

    4.4 Listar contenido del directorio

    Usamos Files.list() que devuelve un Stream<Path>. Es obligatorio cerrarlo, así que lo envolvemos en try-with-resources. Además distinguimos visualmente entre ficheros y directorios:

    try (Stream<Path> contenido = Files.list(base)) {
    contenido.forEach(entry -> {
        String tipo = Files.isDirectory(entry) ? "[DIR] " : "[FIC] ";
        System.out.println(tipo + entry.getFileName());
    });
}

    Mejora: ordenar la lista

    Puedes aprovechar que Files.list() devuelve un Stream para ordenar, filtrar, etc.:

    try (Stream<Path> contenido = Files.list(base)) {
    contenido
        .sorted()
        .forEach(entry -> {
            String tipo = Files.isDirectory(entry) ? "[DIR] " : "[FIC] ";
            System.out.println(tipo + entry.getFileName());
        });
}

    4.5 Eliminar fichero o directorio

    Usamos Files.deleteIfExists() que elimina el elemento si existe y devuelve true, o devuelve false si no existía. Esto evita la excepción NoSuchFileException que lanzaría Files.delete():

    System.out.print("Nombre del fichero o directorio a eliminar: ");
String nombre = sc.nextLine();
Path target = base.resolve(nombre);
boolean eliminado = Files.deleteIfExists(target);
if (eliminado) {
    System.out.println("Eliminado correctamente.");
} else {
    System.out.println("No existe: " + nombre);
}

    Directorios no vacíos

    Files.delete() y Files.deleteIfExists() solo pueden eliminar directorios vacíos. Si el directorio contiene ficheros, se lanzará DirectoryNotEmptyException. Para eliminar un directorio con contenido habría que recorrerlo primero y eliminar su contenido recursivamente (por ejemplo con Files.walkFileTree()).

    6. Objetivo de aprendizaje

    Al finalizar este ejercicio deberías ser capaz de:

    • Crear y manipular rutas con Path y Path.of().
    • Usar Files para crear, listar y eliminar ficheros y directorios.
    • Comprender las ventajas de java.nio.file frente a java.io.File.
    • Aplicar try-with-resources con Stream<Path> al listar directorios.
    • Gestionar errores del sistema de archivos mediante excepciones.

    7. Resumen: java.io.File vs java.nio.file

    Aspecto java.io.File (antiguo) java.nio.file (moderno)
    Representar ruta new File("datos") Path.of("datos")
    Combinar rutas new File(base, nombre) base.resolve(nombre)
    Crear directorio file.mkdir() → boolean Files.createDirectories(path) → excepción si falla
    Crear fichero file.createNewFile() → boolean Files.createFile(path) → excepción si falla
    Listar contenido file.listFiles() → File[] Files.list(path) → Stream<Path>
    Eliminar file.delete() → boolean Files.deleteIfExists(path) → boolean + excepción si error
    Comprobar existencia file.exists() Files.exists(path)
    Gestión de errores Silenciosa (true/false) Excepciones descriptivas
