    📘 Introducción a Operadores en Java

    🔹 Operadores de Comparación

    En Java, los operadores de comparación devuelven un valor booleano (true o false):

    Operador Ejemplo Significado
    == a == b Igual a
    != a != b Distinto de
    > a > b Mayor que
    < a < b Menor que
    >= a >= b Mayor o igual que
    <= a <= b Menor o igual que

    Los operadores de comparación permiten comparar valores. El resultado siempre es booleano (true o false).

    Ejemplos:

    1) Igualdad

    Pseudocódigo:

    si (x == y) entonces
    mostrar "Son iguales"

    Java:

    if (x == y) {
    System.out.println("Son iguales");
}

    2) Distinto de

    Pseudocódigo:

    si (x != y) entonces
    mostrar "Son diferentes"

    Java:

    if (x != y) {
    System.out.println("Son diferentes");
}

    3) Mayor que

    Pseudocódigo:

    si (edad > 18) entonces
    mostrar "Eres mayor de edad"

    Java:

    if (edad > 18) {
    System.out.println("Eres mayor de edad");
}

    4) Menor o igual que

    Pseudocódigo:

    si (nota <= 5) entonces
    mostrar "Has suspendido"

    Java:

    if (nota <= 5) {
    System.out.println("Has suspendido");
}

    🔹 Operadores Lógicos

    Se usan para combinar condiciones:

    Operador Ejemplo Significado
    && (a > 0 && b > 0) AND → ambas condiciones deben ser ciertas
    || (a > 0 || b > 0) OR → al menos una condición debe ser cierta
    ! !(a > 0) NOT → niega la condición

    Los operadores lógicos permiten combinar varias condiciones.

    Ejemplos:

    1) AND (&&)

    Pseudocódigo:

    si (edad >= 18 Y edad <= 65) entonces
    mostrar "Edad laboral"

    Java:

    if (edad >= 18 && edad <= 65) {
    System.out.println("Edad laboral");
}

    2) OR (||)

    Pseudocódigo:

    si (dia == "Sábado" O dia == "Domingo") entonces
    mostrar "Es fin de semana"

    Java:

    if (dia.equals("Sábado") || dia.equals("Domingo")) {
    System.out.println("Es fin de semana");
}

    3) NOT (!)

    Pseudocódigo:

    si (NO (tienePermiso)) entonces
    mostrar "Acceso denegado"

    Java:

    if (!tienePermiso) {
    System.out.println("Acceso denegado");
}

    🟢 Bloque 1: Condicionales en Java

    📌 Sintaxis Básica

    if (condicion) {
    // se ejecuta si es verdadero
} else if (otraCondicion) {
    // se ejecuta si la otra condición es verdadera
} else {
    // se ejecuta si ninguna condición se cumple
}

switch (variable) {
    case valor1:
        // código
        break;
    case valor2:
        // código
        break;
    default:
        // si no coincide ningún caso
}

    🚀 Ejercicios de Condicionales

    1) ¿Positivo o Negativo?

    Objetivo: Determinar si un número introducido por el usuario es positivo, negativo o cero.

    Tarea a realizar: Pedir un número entero y evaluarlo con un if-else if-else.

    Aplicación en el Mundo Real: Validar valores en sensores (ej: temperatura por debajo de 0, mayor que 0, igual a 0).

    2) Par o Impar

    Objetivo: Verificar si un número es par o impar usando %.

    Aplicación en el Mundo Real: Determinar si un ticket de entrada corresponde a par/impar para acceso alternado.

    3) El Mayor de Dos Números

    Objetivo: Comparar dos números y mostrar cuál es mayor.

    Aplicación en el Mundo Real: Comparar puntuaciones de dos jugadores.

    4) Clasificación de Edad

    Objetivo: Usar if-else if para clasificar la edad en: Niño, Adolescente, Adulto.

    Aplicación en el Mundo Real: Definir tarifas en cine según rango de edad.

    5) Nota en Palabras

    Objetivo: Convertir una nota numérica en texto (Sobresaliente, Notable, Aprobado, Suspenso).

    Aplicación en el Mundo Real: Sistemas de evaluación académica.

    6) Menú de Opciones con Switch

    Objetivo: Usar switch para mostrar diferentes mensajes según la opción elegida.

    Aplicación en el Mundo Real: Menús de cajeros automáticos o aplicaciones.

    7) Día de la Semana

    Objetivo: Usar switch para mostrar el día según el número (1=Lunes, 7=Domingo).

    Aplicación en el Mundo Real: Planificación de agendas o calendarios.

    8) Año Bisiesto

    Objetivo: Determinar si un año es bisiesto.

    Aplicación en el Mundo Real: Sistemas de calendario.

    9) Calculadora con Switch

    Objetivo: Implementar una mini calculadora con operaciones básicas.

    Aplicación en el Mundo Real: Funcionalidad inicial de apps de calculadora.

    10) Descuentos según Cliente

    Objetivo: Aplicar descuentos según tipo de cliente (Normal, Premium, VIP).

    Aplicación en el Mundo Real: Comercio electrónico.
