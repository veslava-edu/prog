Objetivos del módulo

a. Estructura de programa
Identificar elementos básicos y crear proyectos con variables y operadores
  • Identificar bloques de estructura
  • Crear proyectos y usar entornos de desarrollo
  • Identificar tipos de variables
  • Crear constantes y literales
b. Programación POO básica
Aplicar fundamentos de POO creando programas simples con objetos y métodos
  • Identificar fundamentos de POO
  • Escribir programas simples
  • Instanciar objetos. Utilizar métodos y propiedades
  • Llamar a métodos estáticos
c. Estructuras de control
Utilizar estructuras de selección, repetición y manejo de excepciones
  • Utilizar estructuras de selección y repetición
  • Reconocer sentencias de salto
  • Utilizar control de excepciones
  • Probar y depurar programas
d. Programas en clases
Desarrollar programas organizados en clases con herencia e interfaces
  • Definir clases, propiedades y métodos
  • Crear constructores
  • Controlar visibilidad
  • Definir clases heredadas e interfaces
e. Operaciones de E/S
Realizar operaciones de entrada/salida y crear interfaces gráficas
  • Utilizar consola para E/S
  • Aplicar formatos en visualización
  • Utilizar ficheros
  • Crear interfaces gráficas y programar controladores
f. Tipos avanzados de datos
Manipular información con arrays, listas y expresiones regulares
  • Utilizar arrays, listas e iteradores
  • Reconocer colecciones de datos
  • Crear clases genéricas
  • Utilizar expresiones regulares
g. POO avanzada
Aplicar herencia, polimorfismo y diseñar jerarquías de clases
  • Identificar conceptos de herencia
  • Crear clases heredadas
  • Diseñar jerarquías de clases
  • Probar jerarquías de clases
h. BDOO
Utilizar bases de datos orientadas a objetos para persistencia de datos
  • Dominar sistemas gestores BDOO
  • Crear bases de datos
  • Programar aplicaciones con BDOO
  • Recuperar, actualizar objetos
i. Bases de datos relacionales
Gestionar información en bases de datos relacionales con integridad
  • Identificar características SGBD
  • Programar conexiones con BD
  • Almacenar recuperar y mostrar información
  • Ejecutar consultas sobre BD
