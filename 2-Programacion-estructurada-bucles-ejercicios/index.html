    Ejercicios Prácticos: Programación Estructurada - Bucles

    ¡Equipo de desarrollo! Bienvenidos a vuestra primera asignación en el proyecto "Nexus Engine", nuestro motor de videojuegos de nueva generación. Vuestra misión es desarrollar una serie de pequeñas herramientas y prototipos que formarán el núcleo de la lógica del motor. Hoy nos centraremos en una de las herramientas más potentes de nuestro arsenal: los bucles. Con ellos, daremos vida a simulaciones, automatizaremos tareas repetitivas y gestionaremos la lógica de juego que se ejecuta fotograma a fotograma. ¡Manos al código!

    Ejercicios de Consolidación

    1) Contador de Lanzamiento de Hechizos | Nivel: Fácil

    Objetivo

    Utilizar un bucle for para ejecutar una acción un número predefinido de veces.

    Tarea a realizar

    En muchos juegos de rol, algunos hechizos golpean varias veces, como una "Lluvia de Meteoritos". Crea un programa que simule el lanzamiento de un hechizo que golpea 5 veces. Por cada golpe, debe imprimir en la consola un mensaje indicando el número del impacto.

    Salida esperada: 

    ¡Lanzando Lluvia de Meteoritos!
Impacto de meteorito número 1
Impacto de meteorito número 2
Impacto de meteorito número 3
Impacto de meteorito número 4
Impacto de meteorito número 5

    Aplicación en el Mundo Real

    Este patrón se usa constantemente para gestionar efectos de daño sobre tiempo (DoT), animaciones que se repiten un número fijo de veces, o para procesar un número conocido de entidades en el juego.

    2) Simulador de Barra de Experiencia | Nivel: Fácil

    Objetivo

    Implementar un bucle while que se ejecute mientras una condición sea verdadera.

    Tarea a realizar

    Un personaje del juego necesita 100 puntos de experiencia (XP) para subir de nivel. Actualmente tiene 0 XP. Cada vez que derrota a un enemigo, gana 15 XP.

    Crea un programa que simule este proceso. El programa debe ir sumando 15 XP al total y mostrando el mensaje "¡Has ganado 15 XP! XP totales: [XP_actuales]" hasta que el personaje alcance o supere los 100 XP. Al final, debe mostrar el mensaje "¡Ding! Has subido de nivel.".

    Aplicación en el Mundo Real

    Los bucles while son el núcleo de la mayoría de los bucles de juego (game loops), que se ejecutan continuamente mientras el jugador no haya salido de la partida o mientras una condición de victoria/derrota no se haya cumplido.

    3) Menú de Crafting Básico | Nivel: Fácil

    Objetivo

    Utilizar un bucle do-while para garantizar que un bloque de código se ejecute al menos una vez.

    Tarea a realizar

    Necesitamos un menú para la mesa de crafteo del juego. El menú debe mostrarse al menos una vez y repetirse hasta que el jugador elija la opción de salir (opción 0).

    El programa debe: 1. Mostrar las opciones del menú. 2. Pedir al usuario que introduzca una opción. 3. Repetir el proceso si la opción introducida no es 0. 4. Cuando el usuario introduzca 0, mostrar un mensaje de despedida.

    Aplicación en el Mundo Real

    Los bucles do-while son perfectos para menús interactivos y para la validación de entradas de usuario, ya que siempre necesitas pedir la entrada al menos una vez antes de poder comprobar si es válida o si el usuario quiere salir.

    4) Listado de Ítems del Inventario | Nivel: Fácil

    Objetivo

    Recorrer todos los elementos de un array utilizando el bucle for-each.

    Tarea a realizar

    El motor del juego necesita una forma de mostrar el inventario del jugador. Dado un array de String que representa los ítems, crea un programa que recorra el array e imprima cada ítem en una nueva línea, precedido por un guion.

    Setup Inicial
    String[] inventario = {"Espada de Hierro", "Poción de Salud", "Antorcha", "Mapa Antiguo"};
    Aplicación en el Mundo Real

    El bucle for-each es la forma más común, segura y legible de procesar cada elemento de una colección de datos (arrays, listas, etc.). Se usa para renderizar listas en interfaces de usuario, aplicar un efecto a todos los enemigos en una zona o, como en este caso, listar inventarios.

    5) Generador de Coordenadas de un Mapa | Nivel: Fácil

    Objetivo

    Comprender el funcionamiento de los bucles anidados (nested loops).

    Tarea a realizar

    Para generar proceduralmente un mapa, a menudo necesitamos iterar sobre una rejilla o grid. Crea un programa que utilice dos bucles for anidados para imprimir todas las coordenadas [x, y] de un mapa de 5x5. El contador x (externo) y el contador y (interno) deben ir de 0 a 4.

    Salida esperada (extracto): 

    [0, 0] [0, 1] [0, 2] [0, 3] [0, 4] 
[1, 0] [1, 1] [1, 2] [1, 3] [1, 4] 
...
[4, 0] [4, 1] [4, 2] [4, 3] [4, 4]

    Aplicación en el Mundo Real

    Los bucles anidados son fundamentales en el procesamiento de datos bidimensionales como imágenes (píxel a píxel), matrices en cálculo científico, o tableros y mapas en videojuegos.

    6) Debugging: Bug en el Cálculo de Daño por Segundo (DPS) | Nivel: Fácil

    Objetivo

    Identificar y corregir un error común en un bucle while que provoca un bucle infinito.

    Tarea a realizar

    El siguiente código intenta simular el daño de un veneno que hace 10 de daño por segundo durante 5 segundos. Sin embargo, el código contiene un error que provoca que se ejecute indefinidamente. Encuentra el bug y corrígelo.

    Setup Inicial (Código con Bug)
    public class CalculoDpsBug {
    public static void main(String[] args) {
        int tiempoTotal = 5;
        int tiempoTranscurrido = 0;
        int danoPorSegundo = 10;
        int danoTotal = 0;

        System.out.println("El veneno empieza a hacer efecto...");

        while (tiempoTranscurrido < tiempoTotal) {
            danoTotal += danoPorSegundo;
            System.out.println("Segundo " + (tiempoTranscurrido + 1) + ": Daño acumulado: " + danoTotal);
            // Falta algo aquí...
        }

        System.out.println("El efecto del veneno ha terminado. Daño total infligido: " + danoTotal);
    }
}
    Aplicación en el Mundo Real

    Los bucles infinitos son uno de los errores más comunes y frustrantes para los programadores junior. Aprender a detectarlos es una habilidad de depuración esencial que te ahorrará horas de trabajo. La causa suele ser una condición de salida que nunca se alcanza.

    Ejercicios de Refuerzo

    7) Análisis de Loot Drop | Nivel: Medio

    Objetivo

    Combinar un bucle for con condicionales if-else if-else para simular un sistema con probabilidades.

    Tarea a realizar

    Vamos a simular la apertura de 10 "Cajas de Botín". Por cada caja, se debe generar un número aleatorio entre 1 y 100 que determinará la rareza del ítem obtenido, según las siguientes reglas: * 1-60: Común * 61-85: Raro * 86-98: Épico * 99-100: Legendario

    El programa debe iterar 10 veces. En cada iteración, generará el número aleatorio e imprimirá un mensaje como: "Caja 1: Has sacado un 78. ¡Ítem Raro!"

    Pista

    Puedes generar un número aleatorio entre 1 y 100 usando new Random().nextInt(100) + 1;. No olvides importar java.util.Random.

    Aplicación en el Mundo Real

    Este tipo de lógica es el corazón de cualquier sistema basado en probabilidades ("gacha", "loot boxes", crafteo con posibilidad de fallo). Simular estos sistemas ayuda a los diseñadores de juegos a equilibrar la economía y la recompensa para el jugador.

    8) Creación de Personaje: Validación de Puntos de Atributo | Nivel: Medio

    Objetivo

    Utilizar un bucle do-while para validar una entrada de usuario compleja que debe cumplir una condición específica.

    Tarea a realizar

    Durante la creación de un personaje, el jugador dispone de 20 puntos para distribuir entre tres atributos: Fuerza, Destreza e Inteligencia. El programa debe pedir al jugador que introduzca los puntos para cada uno de los tres atributos.

    El programa debe usar un bucle do-while para repetir la petición de los tres valores hasta que la suma total de los puntos introducidos sea exactamente 20. Si la suma es distinta de 20, debe mostrar un mensaje de error y volver a pedir los tres valores.

    Pista

    Declara las variables para los tres atributos fuera del bucle. Dentro del do-while, pide los tres valores y calcula la suma. La condición del while al final será sumaTotal != 20.

    Aplicación en el Mundo Real

    La validación de formularios es una tarea diaria para cualquier desarrollador. Asegurarse de que los datos introducidos por un usuario cumplen con las reglas del negocio (la suma es correcta, un campo no está vacío, un email tiene el formato adecuado) antes de procesarlos es crucial para evitar errores.

    9) Renderizador de Texto de Combate | Nivel: Medio

    Objetivo

    Procesar un String carácter por carácter utilizando un bucle for y métodos de la clase String.

    Tarea a realizar

    Para darle un toque retro a nuestro motor, vamos a crear un efecto de "máquina de escribir" para los mensajes de combate. Dado un String con un mensaje, el programa debe imprimirlo en la consola carácter por carácter, con una pequeña pausa de 50 milisegundos entre cada carácter.

    Setup Inicial
    String mensaje = "El Dragón Primordial lanza una llamarada...";
    Pista

    Puedes obtener la longitud de un String con el método .length() y acceder a un carácter en una posición específica con .charAt(index). Para la pausa, puedes usar Thread.sleep(50);. Recuerda que Thread.sleep puede lanzar una InterruptedException, por lo que necesitarás rodearlo con un bloque try-catch.

    Aplicación en el Mundo Real

    El procesamiento de cadenas carácter a carácter es fundamental en tareas de parsing (análisis de texto), como leer un fichero de configuración CSV, analizar una URL, o validar que una contraseña cumple con ciertos requisitos (contiene mayúsculas, números, etc.).

    Ejercicios de Ampliación

    10) Generador de Arte ASCII para Pantallas de Carga | Nivel: Alto

    Objetivo

    Aplicar bucles anidados y condicionales para resolver un problema de lógica y generación de patrones.

    Tarea a realizar

    Las pantallas de carga son más interesantes con algo de arte ASCII. Tu tarea es escribir un programa que genere un triángulo rectángulo y un rombo usando asteriscos (*). El usuario debe poder especificar el tamaño.

    1. Pide al usuario un número entero n (por ejemplo, 5).
    2. Usando bucles anidados, imprime un triángulo rectángulo de n filas.
    3. A continuación, imprime un rombo de altura 2*n - 1.

    Ejemplo de salida para n = 5:

    Triángulo: 

    *
**
***
****
*****

    Rombo: 

        *
   ***
  *****
 *******
*********
 *******
  *****
   ***
    *

    Aplicación en el Mundo Real

    Aunque generar arte ASCII es un ejercicio clásico, la lógica subyacente es la misma que se usa para renderizar formas en gráficos 2D (calculando qué píxeles activar en una rejilla), generar terrenos procedurales o resolver problemas de programación algorítmica en entrevistas técnicas.

    11) Simulador de Economía de Mercado | Nivel: Alto

    Objetivo

    Modelar un sistema dinámico simple a lo largo del tiempo usando bucles y lógica condicional, y realizar un seguimiento de los datos generados.

    Tarea a realizar

    Vamos a simular el precio de un ítem ("Poción de Maná") en el mercado del juego durante 30 días. * El precio inicial es de 50.0 monedas. * Cada día (cada iteración de un bucle for de 1 a 30), el precio cambia. Genera un número aleatorio entre -3.0 y +3.0 para simular la fluctuación. * Añade una regla de mercado: si el precio sube por encima de 60.0, hay un 75% de probabilidad de que al día siguiente la fluctuación sea negativa (la gente vende). Si baja de 40.0, hay un 75% de probabilidad de que la fluctuación sea positiva (la gente compra). * Durante la simulación, mantén un registro del precio más alto y el más bajo alcanzado. * Al final de los 30 días, imprime el precio final, el precio máximo y el precio mínimo registrados.

    Aplicación en el Mundo Real

    Este tipo de simulación (conocida como "Simulación de Monte Carlo" en su forma más avanzada) se utiliza en finanzas para predecir el comportamiento de los mercados, en ciencia para modelar sistemas complejos y en diseño de juegos para asegurar que la economía interna sea estable y no se "rompa" con el tiempo.

    12) Algoritmo de Detección de Patrones de IA | Nivel: Alto

    Objetivo

    Resolver un problema algorítmico más abierto que requiere bucles anidados, manipulación de String y lógica de conteo.

    Tarea a realizar

    El equipo de IA nos ha pedido una herramienta para analizar el comportamiento de los enemigos. Nos han proporcionado un String que representa la secuencia de acciones de un enemigo en un combate (ej: A=Atacar, B=Bloquear, D=Defender).

    Tu tarea es encontrar la secuencia de dos acciones consecutivas que más se repite. Por ejemplo, en la secuencia "ABABDABAC", el par "AB" se repite 3 veces, "BA" se repite 2 veces, "BD" 1 vez, etc. El programa debería identificar que "AB" es el patrón más frecuente.

    Setup Inicial
    String secuenciaIA = "ADDBABADAABBCADAB";
    Tarea de Peer Review

    Una vez que tengas una solución funcional, intercámbiala con un compañero. Revisa su código y responde a estas preguntas: 1. Corrección: ¿El código resuelve correctamente el problema para la secuencia de prueba y para otros casos que se te ocurran (ej: una secuencia vacía, una con un único patrón)? 2. Claridad: ¿Los nombres de las variables son descriptivos? ¿Podrías entender la lógica del programa sin que te la explicaran? 3. Eficiencia (Opcional): ¿Se te ocurre alguna forma de optimizar el código? ¿Realiza algún cálculo innecesario o repetido?

    Aplicación en el Mundo Real

    El análisis de patrones en secuencias es un pilar del machine learning y la data science. Se usa para predecir el comportamiento del consumidor, detectar fraudes en transacciones, analizar secuencias de ADN y, en el mundo de los videojuegos, para crear una IA que pueda aprender y anticiparse a las acciones del jugador.
